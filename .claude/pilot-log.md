# pilot-log — 하네스 재설계 2주 측정 기록

> **2026-08-13 ~ 2026-08-27 한정 산출물이다.** 2주가 끝나면 재평가에서 「계속 / 중단 / 형태 변경」을 정하고,
> 계속이 아니면 이 파일은 `.claude/_archive/` 로 물러난다. 상시 자산이 아니다.
> 목적은 하나다 — **재설계가 실제로 왕복을 줄였는지를 숫자로 확인**하는 것. Phase 0 은 이 숫자를 못 냈다.
> 트랜스크립트가 작업 단위로 쪼개지지 않아 「작업 1건당 스킬 호출 수」를 사후 귀속할 수 없었기 때문이다.
> 그래서 사람이 1줄을 남긴다. 자동 수집 장치는 만들지 않는다 — 2주 쓰고 버릴 것에 스크립트를 붙이면 그 스크립트가 남는다.

## 기입 규칙

- **작업 1건 = 1줄.** 작업의 경계는 `/bts` 1회 진입부터 머지까지다. 중단된 작업도 적는다(재작업 열에 `중단`).
- **적는 시점은 머지 직후.** 게이트 2 요약을 보고 그 자리에서 적는다. 나중에 몰아 적으면 승인 횟수를 못 센다.
- **모르면 `?`.** 빈칸이나 추측값을 넣지 않는다. `?` 가 많은 열은 그 열이 측정 불가라는 사실 자체가 결과다.
- **주 1회 러너 부재 줄**을 §러너 가용성 표에 따로 적는다(아래 규칙 참조).

### 열 정의

| 열 | 무엇을 적나 | 어떻게 얻나 |
|---|---|---|
| 날짜 | 머지한 날 `MM-DD` | — |
| 작업 | 30자 이내 요약 + PR 번호 | — |
| 티어 | 실제로 밟은 절차의 티어 `T0`~`T3` | 게이트 2 요약의 티어 행 |
| 선언≠실측 | 계획서에 적은 티어와 `detect-tier` 실측이 갈렸으면 `선언T1/실측T2` 형태로, 같으면 `=` | 게이트 2 요약이 둘을 나란히 출력한다 |
| 스킬 | 그 작업에서 발동한 `/bts*` 스킬 **호출 수** | 세션에서 발동한 횟수를 센다. 같은 스킬 재호출도 각각 1 |
| 승인 | Maxi 가 손으로 승인·응답한 **정지 횟수** | 게이트 1·2 + 중간 질문. 단순 알림은 제외 |
| 재작업 | `없음` / `있음(사유 10자)` / `중단` | 머지 후 같은 범위를 다시 고쳤으면 `있음` |
| 비고 | 위 열로 안 잡히는 것 1줄 | 선택 |

**「스킬 호출 수」가 이 표의 본체다.** 재설계의 핵심 주장이 「작업당 평균 7.70회 → 5.00회」이고,
그 주장을 반증할 수 있는 유일한 열이다. 다른 열이 비어도 이 열은 채운다.

## 러너 가용성 — 주 1회 1줄

CI 실패의 절반 이상이 「테스트가 깨졌다」가 아니라 **「러너가 없다」** 였다(재설계 직전 30건 중 16건).
2026-08-08 이후 창에서 0건으로 떨어졌는데, **0 이 유지되는지를 아무도 안 보면 재발이 조용히 돌아온다.**
그래서 주 1회 1줄만 남긴다. 자동 감시는 붙이지 않는다 — 비용이 1줄이라 굳이 기계를 만들 이유가 없다.

세는 법. 실패 런 중 **실패 스텝이 `Checkout` 이거나 `러너 엔진 점검`** 인 건수다.

```bash
gh run list --status failure --limit 50 --json databaseId,name,createdAt,conclusion
```

## 2주 뒤에 이 파일로 답할 것

1. **스킬 호출 수 평균이 5.00 근처인가.** 크게 위면 티어 판정이 T2 로 쏠린 것이고, 아래면 절차를 건너뛴 것이다 — 어느 쪽인지는 티어 열이 말해 준다.
2. **선언≠실측이 몇 건인가.** 이 열이 자주 갈리면 「모델이 자기 티어를 적는다」는 구조가 못 미더운 것이고, 표면 기준 하한 판별식을 넓혀야 한다.
3. **재작업이 티어와 상관 있나.** T0/T1 에서 재작업이 몰리면 절차를 너무 깎은 것이다. 이것이 「완화가 지나쳤나」를 재는 유일한 신호다.
4. **승인 횟수가 줄었나.** 줄지 않았다면 이득은 왕복이 아니라 다른 데(호출 수) 있었다는 뜻이고, 그 사실을 그대로 기록한다.
5. **러너 부재 0 이 유지됐나.**

답을 낼 때 **표본 수와 창을 같이 적는다.** 5건짜리 평균을 15일 분포처럼 읽으면 오도된다.
