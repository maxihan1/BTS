FR-WF-02 D6 — 워크플로우 스킴 관리 UI 시안 비교

화면 = 스킴 상세 + 매핑 편집 (가장 정보 위계 결정 중요한 화면). 색/폰트는 DESIGN.md 고정. 레이아웃·정보위계·매핑 편집 패턴·액션 위치로 차별화.

1

Multi-pane admin console

3-컬럼. 좌 사이드바 (스킴 네비) + 중앙 매핑 테이블 + 우 메타패널. PR #26 의 사이드 메타패널 taste 직접 계승.
  • 정보 밀도 최고 (한 화면에 모든 컨텍스트)
  • 스킴 간 전환 빠름 (좌 네비)
  • 광폭 모니터 admin 워크플로우 최적
  • 1280px 미만에서 컬럼 압박
  • 모바일 대응 필요 시 별도 레이아웃
새 탭에서 열기 →
2

Top-down stacked

풀폭 single-column (~880px). default mapping highlight 카드 + 매핑 테이블 + 사용 프로젝트 카드. primary CTA "＋ 매핑 추가" 상단 우.
  • default mapping 시각적 강조 (★ + 색)
  • 모바일 대응 자연 (single-column)
  • CTA 위치 명확 (상단 primary)
  • 스킴 간 전환은 별 페이지 (목록 → 상세)
  • 좌측 네비 부재로 컨텍스트 약함
새 탭에서 열기 →
3

Card grid + drawer

스킴 목록 = 카드 그리드 (3-col). 카드 클릭 → 우 480px drawer slide-in (매핑 + 메타). Linear/Notion 풍.
  • 스킴 개요 한 눈 (카드별 매핑/프로젝트 수)
  • drawer 로 컨텍스트 유지하며 편집
  • 가벼운 미적 (admin 무거움 회피)
  • 매핑 편집 영역이 drawer 라 좁음 (480px)
  • 카드 그리드와 drawer 동시 노출 시 시각 복잡
새 탭에서 열기 →
4

Master-detail single screen

한 화면 좌 = 스킴 compact list (검색 가능) + 우 = full editor. URL `?selected=software` 로 컨텍스트 유지. 페이지 전환 없음.
  • 스킴 비교 빠름 (좌 list 의 매핑/프로젝트 수)
  • full editor 영역 넓음 (drawer 보다 우세)
  • 검색 자연 (좌 list 상단)
  • 좌 list + 우 editor 양분 시 모바일 대응 어려움
  • URL 쿼리 패턴이 TanStack Router file-route 와 비대칭

선택 기준 제안

  • 시안 1 (Multi-pane) — PR #26 taste 직접 계승, admin 도구 정보 밀도 최우선이면 선택.
  • 시안 2 (Top-down) — default mapping 강조 + 모바일 대응 우선, primary CTA 위치 명확하게 가고 싶으면.
  • 시안 3 (Card + drawer) — 가벼운 미적, 스킴 목록을 카드로 일목요연하게 보여주고 싶을 때.
  • 시안 4 (Master-detail) — 스킴 간 비교 + 검색이 핵심 use case, full editor 영역도 넓게 쓰고 싶을 때.
