## 1. 색

**밝게 · 어둡게 둘 다 둬요.** 처음에는 컴퓨터 설정(`prefers-color-scheme`)을 따르고, 사람이 바꾸면 그 선택을 기억해요.

### 대표색 — 오렌지 하나
| 쓰임 | 밝게 | 어둡게 |
|---|---|---|
| 채움(주 버튼 · 로고 · 진행 막대) | `#FF7A1A` | `#FF7A1A` |
| 채움 위 글자 | `#1A0D02` | `#1A0D02` |
| 글자로 쓸 때(링크 · 강조 숫자) | `#B84D05` | `#FF9A4D` |
| 옅은 바탕(고른 줄 · 칩) | `#FFF1E6` | `rgba(255,122,26,.13)` |

- **대표색 자리는 다섯 곳뿐이에요.** 누를 것, 지금 고른 것, 진행 중인 것, 새 알림, 로고예요.
- 그래프 수치에는 대표색을 쓰지 않아요. 판정 색과 회색 단계로 그려요.
- 주 버튼(채운 오렌지)은 한 화면에 하나예요. 줄마다 되풀이되는 버튼은 테두리 버튼으로 해요.

### 판정 색 — 판정에만
| 판정 | 밝게(칠 · 글자) | 어둡게(칠 · 글자) |
|---|---|---|
| 통과 | `#16A34A` · `#15803D` | `#3FB871` · `#6FD49A` |
| 실패(진홍) | `#D4294F` · `#B81E42` | `#EE3D63` · `#FF8AA3` |
| 미실행 · 없음 | `#9AA1AD` | `#7D8592` |

- 줄 안에서 판정 색이 보이면 그건 판정이에요. 다른 뜻으로 쓰지 않아요.
- 예외는 하나예요. 실패 색은 입력 오류 표시에도 써요.
- 되돌릴 수 없는 일(삭제 · 중단) 단추는 판정 색 대신 **잉크 채움**(밝게 `#15171C` · 어둡게 `#ECEDEF`)으로 해요.
- 실패를 오렌지 쪽 빨강으로 옮기지 않아요. 대표색과 헷갈려요.

## 2. 글꼴
- 본문은 **IBM Plex Sans KR**(400 · 600 두 굵기)이에요.
- 숫자 · ID · 코드는 **IBM Plex Mono** 예요. 숫자는 늘 `font-variant-numeric: tabular-nums` 로 세로를 맞춰요.
- 큰 숫자(대시보드 숫자 칸)는 **IBM Plex Sans Condensed 600** 이에요.
- 글꼴 파일은 제품 안에 넣어요. 사내망에서 CDN 이 막히면 숫자 폭이 어긋나요.

## 3. 모양
- 판 radius 8px, 버튼 · 입력 칸 6px, 칩은 둥근 알약 모양이에요.
- 행(줄)은 카드로 감싸지 않고 괘선으로 나눠요.
- 그림자는 다른 화면 위에 뜨는 것(창 · 서랍 · 팝오버 · 토스트)에만 줘요.

## 4. 움직임 — QA Hub 와 똑같이
**원칙: 움직임은 바뀐 것만 알려요.**

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--t1` | 0.12초 | 누름 · 색 바뀜 · 마우스 올림 |
| `--t2` | 0.2초 | 화면 열기 · 서랍 · 탭 밑줄 · 창 |
| `--t3` | 0.3초 | 아래 판 · 막대 자람 · 선 그리기 |
| 숫자 | 0.4초 | 숫자 올라가기(유일한 0.3초 넘는 예외) |
| 곡선 | `cubic-bezier(.2,.8,.2,1)` | 하나만 써요. 데이터를 그리는 움직임에 튕김(넘침)을 쓰지 않아요 |

- **처음 열 때**: 판이 아래에서 6px 떠오르며 50ms 간격으로 차례로 나와요. 여섯 번째부터는 같이 나오고, 다 합쳐 0.5초 안에 끝나요.
- **되풀이 움직임은 둘뿐**이에요. 맥박(실행 중 점 · 기다림 점, 1.6초)과 불러오는 중 뼈대 위를 훑는 빛(1.2초)이에요. 기다리는 동안만 돌아요.
- **움직임 목록**
  - 화면 열기: 판이 차례로 떠오름. 휴대폰에서 목록 → 상세는 오른쪽에서 밀려 들어옴
  - 숫자는 0에서 올라가고, 막대는 왼쪽부터 자라고, 선 그래프는 그려짐
  - 불러오는 중: 줄 모양 회색 뼈대 + 빛이 훑음. 다 오면 뼈대째 사라짐
  - 서랍: 오른쪽에서(휴대폰은 아래에서) 미끄러져 들어옴
  - 지금 위치 표시(왼쪽 줄 막대 · 탭 밑줄): 새 자리로 미끄러져 옮겨 감
  - 누름: 0.96배로 살짝 눌림
  - 서버를 기다리는 단추: 폭은 그대로, 맥박 점 + 「~하는 중…」
  - 토스트: 아래에서 떠오르고 3초 뒤 사라짐
  - 새 알림: 알림 점이 한 번 커졌다 돌아옴
  - 증거 · 탭 내용 바꾸기: 겹쳐 바뀜. 실패 확인 줄은 한 번 진하게 깜박
  - 밝게 · 어둡게 전환: 화면 전체가 0.2초 겹쳐 바뀜(View Transitions)
  - 창: 열 때만 떠오르고, 닫을 때는 바로 사라짐
- **「움직임 줄이기」(`prefers-reduced-motion`)를 켠 사람에게는 모든 움직임을 끄고** 바뀐 상태만 바로 보여요. 일부만 끄지 않아요.

## 5. 창(모달) · 서랍
- **화면이 여는 확인 창은 아껴 써요.** 되돌릴 수 없는 일 전 확인, 실행 전 값 확인, 저장 안 하고 떠나기 같은 자리에만 둬요. 알림 · 안내 · 오류는 화면 안의 줄로 적어요.
- **사람이 여는 창**은 목록을 떠나지 않으려고 쓰는 창이에요. 이 창 안에서 물을 일이 생기면 창을 또 겹치지 않고 창 안의 줄로 물어요.
- **상세 보기는 오른쪽 서랍**이에요. 목록을 떠나지 않고, 뒤를 어둡게 하지 않아요.
- `Esc` 는 맨 위 창 하나만 닫아요. 닫으면 포커스는 열기 전 자리로 돌아가요.
- 값을 넣는 창은 바깥을 눌러도 안 닫혀요. 고친 채 닫으면 창의 단추 줄이 「계속 고치기 · 저장 안 하고 닫기 · 저장하고 닫기」로 물어요.
- 뒤 덮개는 검정(밝게 45% · 어둡게 60%)이고 흐리게 처리하지 않아요.
- 첫 포커스는 안전한 단추(「아니오」 · 「머무르기」 · 「취소」)예요.
- 길게 도는 일의 진행 창은 닫으면 작은 진행 알약으로 줄어요. 끝나면 창이 다시 떠서 알려요.

## 6. 휴대폰(창 폭 620px 미만)
- **모든 메뉴가 열려요.** 「PC 에서 여세요」 같은 안내로 막지 않아요.
- 아래 탭은 자주 쓰는 넷 + 「전체」예요. 「전체」를 누르면 아래에서 메뉴판이 올라와 모든 메뉴가 보여요.
- 표는 카드 줄로 바꿔요. 칸은 한 줄로 쌓아요.
- 작은 창은 아래에서 올라오는 판이에요. 손잡이를 아래로 끌거나 바깥을 누르면 닫혀요.
- 값을 넣는 창은 전체 화면이에요. 키보드가 올라와도 주 단추가 가려지지 않게 아래에 붙여요.
- 단추는 엄지가 닿는 아래에 세로로 쌓고, 주 단추를 맨 아래에 둬요.
- 진행 알약은 탭 위에, 여러 건 고르기 바는 탭 자리에 떠요.

## 7. 같은 부품은 같은 모양으로
짜임은 제품마다 달라도, 같은 일을 하는 부품은 모양과 움직임을 맞춰요.
- **필터**: 단추 하나 + 고른 조건 칩(✕ 로 풀기). 판 안의 조건마다 한 줄 설명을 붙이고, 고르면 바로 적용해요. 하나만 고르는 조건에는 체크 네모를 붙이지 않아요.
- **여러 건 고르기**: 고르기 바(실행 · 삭제 등 · 고르기 풀기), 머리 네모 뒤 「조건에 맞는 N건 모두 고르기」 띠, Shift 로 사이 줄 고르기
- **상태 칩 · 판정 칩 · 토스트 · 불러오는 중 뼈대 · 기다림 단추**

## 8. 문구
- 쉬운 한국어로 써요. 영어를 옮긴 말을 쓰지 않아요. 예: 「거르기」 대신 「필터」, 「시험해 보기」 대신 「테스트 실행」, 「치우기」 대신 「삭제」
- 시스템 안쪽 말(표 · 관문 · 판 같은 개발 낱말)을 화면에 옮기지 않아요.
- 결과 말은 QA 표준 용어로 맞춰요. 예: 통과 · 실패 · 미실행 · 회귀 실패(직전 통과 → 이번 실패) · 기존 실패 · 해결
- 버튼은 행위 이름으로 짧게 써요(「실행」 · 「다시 스캔」). 「~하기」로 맺지 않아요.

## 11. BTS 사정 (BTS 가 덧붙임)

### 11.1 무엇이 이기나

| 계약 §2 「깨면 즉사하는 계약」 | **Jira 패리티 계약** | `aria-label` 4종 · `<h1>` verbatim 은 문구 정책(§8)보다 앞선다. 바꿔야 할 문자열이 나오면 이행 묶음 Q6 에서 Maxi 에게 먼저 묻는다 |

### 11.2 ADS v2 토큰 → 공통 토큰

DESIGN.md §2 의 값은 ADS v2(`@atlaskit/tokens@1.4.2`) 이식이다. 이행 때 **값**이 이 문서 §1 로 바뀐다.
shadcn 토큰 이름(`--primary` · `--background` …)을 그대로 두고 값만 갈지, 공통 토큰 이름(`bg` · `panel` …)을 새로 들일지는 Q1 착수 때 정한다.

아래 대응은 **초안**이다 — 값이 자리를 찾는 방향만 적었다. Q1 착수 때 확정한다.

### 11.3 경고색 — 노랑 쪽으로

지금 `--warning` 라이트는 Orange700 `#B65C02` 다. 오렌지 대표색과 나란히 놓이면 「누를 것」인지 「경고」인지 갈리지 않는다.
원문 §9 대로 경고는 **노랑 쪽**으로 옮긴다. 다크(Yellow400 `#E2B203`)는 이미 노랑이라 라이트만 바뀐다.
원문에는 경고 값이 없다 — 값은 Q1 에서 정하고, 대표색 · 실패 색과 따로 읽히는지 대비를 잰다(DESIGN.md §10 표 갱신).

### 11.4 Geist → IBM Plex

- 지금 본문 글꼴은 `Geist Variable`(`@fontsource-variable/geist`, 제품 안에 들어 있음)이고 한글은 OS 글꼴로 넘어간다.
  공통 정책은 IBM Plex Sans KR · Mono · Sans Condensed 셋이다. 지금처럼 **제품 안에 넣는다**(원문 §2 「CDN 금지」와 같은 방향).
- ★`--font-mono` 는 🔒 동결이다(D2Coding 스택 — FR-SR-02 AQL 입력창 overlay 정렬 정본). IBM Plex Mono 로 바꾸려면
  `textarea` 와 overlay `<pre>` 가 같은 스택을 보는지, 한글이 섞인 AQL 에서 하이라이트가 밀리지 않는지를 Q2 에서 재고 동결을 푼다.
  `--syntax-*` 5종(🔒)도 색 정책 아래로 들어오지만 값 변경은 같은 확인을 거친다.

### 11.5 이미 맞는 것 · 이행 때 확인할 것

- **이미 맞는 것.** 다크 모드 3종(`light` · `dark` · `system`, `system` 이면 `prefers-color-scheme` 구독 · `localStorage` 기억) — 원문 §1 첫 문단과 같다.
  그림자는 뜨는 것에만(DESIGN.md §8 `ring-1` 관례) — 원문 §3 과 같은 방향.
- **확인할 것.** `prefers-reduced-motion` 처리는 지금 사이드바 두 곳(`Sidebar.tsx` · `SidebarResizeHandle.tsx`)에만 있다 — 원문 §4 는 「모든 움직임을 끈다」라서 Q3 에서 전역으로 건다.
  처음 방문자의 기본 테마가 `system` 인지 Q1 에서 확인한다.
- **경계 사례 — Maxi 확인 대상.** 원문 §5 「상세 보기는 오른쪽 서랍」은 창 규칙이지만 이슈 상세를 어디에 여는지는 Jira 패리티의 화면 배치이기도 하다.
  Q4 착수 때 이슈 상세 · 보드 카드 상세의 열림 방식을 Maxi 에게 묻는다.
