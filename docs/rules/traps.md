# 좁은 트리거 함정

`CLAUDE.md §함정` 은 상시 적용. 아래는 **그 작업을 할 때만** 걸린다.

- **시각** — 계산값이 거짓말한다. `<button>` 감싸면 복사가 죽는다. 눈확인이 증인.
- **시드** — system admin 은 로그인 200 뒤 MFA 에 막힌다. 전역 권한 먼저.
- **CI** — self-hosted 는 영구 설계. 유료 플랜 금지. 병목은 분 아닌 아티팩트.
- **질문 분할** — 답마다 합리적인데 합치면 가드 0개. 답변 뒤 합산 되짚기.
- **테스트 훅** — 전역 `afterEach` throw 가 cleanup 을 인질로 잡는다. `expect.soft`.
- **낡은 결과** — lint 가 먼저 죽으면 직전 test XML 이 남는다. 신선도도 본다.
