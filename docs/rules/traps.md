# 좁은 트리거 함정

`CLAUDE.md §함정` 은 상시 적용. 아래는 **그 작업을 할 때만** 걸린다.

- **시각** — 계산값이 거짓말한다. `<button>` 감싸면 복사가 죽는다. 눈확인이 증인.
- **시드** — system admin 은 로그인 200 뒤 MFA 에 막힌다. 전역 권한 먼저.
- **CI 상태** — 머신이 살아남는다. 고정 이름·고정 포트는 뒤 빌드가 앞 빌드를 죽인다. `${BUILD_TAG}` + `docker port`.
- **CI 기동** — CasC 가 죽어도 컨테이너는 `Up` 이다. 503 을 「아직 뜨는 중」으로 읽지 마라. 로그가 증인.
- **CI 성능** — `GRADLE_OPTS` 가 `gradle.properties` 를 덮는다. 파일만 읽는 계약 판별식은 초록인 채 설정이 꺼진다.
- **질문 분할** — 답마다 합리적인데 합치면 가드 0개. 답변 뒤 합산 되짚기.
- **테스트 훅** — 전역 `afterEach` throw 가 cleanup 을 인질로 잡는다. `expect.soft`.
- **낡은 결과** — lint 가 먼저 죽으면 직전 test XML 이 남는다. 신선도도 본다.
- **젠킨스 파라미터** — 새 파라미터는 **Jenkinsfile 을 파싱해야** 생긴다. 등록 전에 넘긴 값은
  에러가 아니라 **조용히 버려진다**(SECURITY-170). 받는 쪽은 기본값으로 돈다. 한 번 돌린 뒤 쓴다.
- **worktree 훅** — `core.hooksPath` 가 절대경로면 어느 worktree 에서 푸시하든 **메인 체크아웃의**
  훅이 돈다. 훅을 고쳐도 안 돌고, 저장소 파일을 읽는 판별식은 초록이다. `.husky/_` 상대경로로 둔다.
- **주석이 코드를 삼킨다** — 안 닫힌 `/**` 아래 `test(` 는 조용히 안 돈다. 브랜치 글로브 표기의
  닫는 표식은 블록 주석을 **끊는다**. 둘 다 이 세션에서 실제로 터졌다.
