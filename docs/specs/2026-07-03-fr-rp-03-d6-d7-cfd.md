## 배경

CFD(Cumulative Flow Diagram, 누적 흐름 다이어그램)는 시간축 위에서 각 워크플로우 상태 카테고리(TODO/IN_PROGRESS/DONE)에 머문 이슈 개수를 누적 영역으로 쌓아 WIP·병목을 시각화하는 애자일 리포트다. 백엔드 시계열 계산은 이미 완료됐고, 이 작업은 그 응답을 **recharts 누적 영역 차트(stacked area)**로 렌더하는 프론트엔드 D6/D7이다.

## 백엔드 계약 (grep 확정, invent 금지)

`GET /api/v1/projects/{projectKey}/cfd?from=&to=` → `200 { data: CfdResponse }`

```
CfdResponse  = { projectKey: string, from: "yyyy-MM-dd", to: "yyyy-MM-dd", points: CfdPointResponse[] }
CfdPointResponse = { date: "yyyy-MM-dd", todoCount: int, inProgressCount: int, doneCount: int }
```

- 외피 = `DataResponse<CfdResponse>` (`data` 필드). 벨로시티 `DataResponse` 동형.
- `from`/`to`/`date`는 LocalDate → **ISO 문자열**(prod `WebMvcConfigurer` 직렬화). Zod `z.string()`.
- **counts 3종은 전부 non-null `Int`** — 번다운 nullable(remaining/completed)과 달라 `.nullish()` **불필요**. 스키마 단순.
- 창 기본 30일(`DEFAULT_WINDOW_DAYS=30`), 상한 180일(`MAX_WINDOW_DAYS=180`). from/to 생략 시 백엔드가 해석해 실제 창을 `from`/`to`로 echo.
- **points는 창 내 매일 1점을 항상 반환**(`CfdCalculator`: `(0 until windowDays).map`). 유효 요청에서 `points`는 절대 비지 않음(기본 30점). → 빈 상태 판정은 §EC1 참조.
- 400: from/to 파싱 실패·`from > to`·창 180일 초과. 401: actor-first 미인증. 403: `IssueAccessDeniedException`.

## 사용자 시나리오 (Given-When-Then)

- **S1 — 백로그 nav 진입 + 차트 표시.** Given 프로젝트 백로그 페이지, When "프로젝트 뷰 전환" nav의 "누적 흐름도" 링크 클릭, Then `/projects/{key}/reports/cfd`로 이동하고 3띠 누적 영역 차트(role="img" 컨테이너)가 표시된다.
- **S2 — 빈 프로젝트.** Given 이슈가 하나도 없는 프로젝트, When CFD 페이지 진입, Then "표시할 데이터가 없습니다" 안내가 뜨고 차트 컨테이너는 표시되지 않는다.
- **S3 — 권한 없음.** Given 프로젝트 BROWSE 권한 없는 뷰어, When CFD 페이지 진입(403), Then "접근 권한이 없습니다" 안내만 표시(응답 데이터 노출 0).
- **S4 — 로딩.** Given 요청 진행 중, When 응답 대기, Then role="status" 로딩 안내 표시.

## 기능 요구사항 (FR)

- **FR1. 전용 라우트** `/projects/$projectKey/reports/cfd` (reports 네임스페이스, requireAuth 가드). 벨로시티 라우트 미러 — Page + RouteAdapter(useParams) 분리(라우터 비의존 단위 테스트).
- **FR2. 누적 영역 차트** — recharts `AreaChart` + 3개 `Area`(공유 `stackId`). 3띠 = DONE/IN_PROGRESS/TODO. X축=날짜, Y축=이슈 수(정수). 실 렌더 검증은 E2E 위임(jsdom width0 함정).
- **FR3. 순수 변환 함수** `toCfdSeries(response): CfdSeriesPoint[]` (named export, 단위 테스트). `CfdSeriesPoint = { date, todo, inProgress, done }`. recharts 데이터 배열 생성.
- **FR4. 상태 분기** — 로딩(role=status) → 에러(403 forbidden / 그 외 loadFailed) → 빈 데이터(§EC1) → 차트. VelocityReport 미러.
- **FR5. API 클라이언트** `fetchProjectCfd(projectKey)` — GET `/cfd`, `cfdResponseSchema.parse(raw).data`. **v1은 from/to 파라미터 미노출**(백엔드 기본 30일 창 사용, 벨로시티 "limit 미노출" 선례). 날짜 범위 피커는 범위 밖(§OQ1).
- **FR6. 백로그 nav 링크** — 백로그 "프로젝트 뷰 전환" nav에 "누적 흐름도" `Link` 추가(board/timeline/velocity 형제). backlog-labels에 `cfdLink` 추가.
- **FR7. i18n** `cfd-labels.ts` — page(title/description) · series(todo/inProgress/done) · status(loading/forbidden/empty/loadFailed) · chart(ariaLabel/yAxisTitle). 콜론 종결 금지(글로벌 §5).
- **FR8. MSW 핸들러** `cfd-handlers.ts` — 시드 가능 공유 store + `DEFAULT_CFD`(projectKey='ATLAS', backlog-fixtures 정합) 자동 시드(MODE≠test) + `FORBIDDEN_PROJECT_KEY`(403) + `EMPTY_PROJECT_KEY`(전 카운트 0). 픽스처는 `cfdResponseSchema.parse` drift 가드.
- **FR9. router.ts 등록** — `projectCfdRoute` createRoute + adapter import + route tree 추가 + 카운트 주석 **40→41** 정정(1행·513행 enumeration).

## 엣지 케이스

- **EC1. 빈 상태 정의(CFD 고유).** 백엔드는 유효 창에서 항상 매일 1점 반환 → `points`는 절대 비지 않음. 벨로시티 `sprints.length===0` 방식 사용 불가. **빈 상태 = 모든 point의 `todoCount+inProgressCount+doneCount`가 0**(프로젝트에 창 내 이슈 0). 그 경우 안내 문구, 아니면 차트. 순수 판정 함수(예: `isCfdEmpty(response)`)로 분리해 단위 테스트.
- **EC2. 스택 순서.** 누적 순서(아래→위) = **DONE → IN_PROGRESS → TODO**(클래식 CFD: 완료가 바닥에 누적, 백로그가 위). 디자인 리뷰에서 확정(§OQ2).
- **EC3. 정수 축.** Y축은 이슈 수(정수) — recharts `allowDecimals={false}`. 초 단위 formatSeconds(벨로시티) 미사용.
- **EC4. 삭제/재오픈.** 백엔드가 이미 처리(삭제 이슈 창 이탈, 재오픈 시 done 감소). 프론트는 받은 counts를 그대로 렌더.
- **EC5. 403 데이터 비노출.** 에러 상태에서 응답 데이터 화면 노출 0(VelocityReport 미러).
