# FR-SL-05 인터랙티브 PR2 — 담당자 변경 + 코멘트 스펙

> slug: fr-sl-05-pr2 · BC: slack-integration · type: backend
> PR1(#261) 완료 흐름을 미러링하는 연속 작업. 세 액션(완료·담당자·코멘트) 모두 **버튼→모달→view_submission** 단일 패턴(Maxi 확정, B형).

## 사용자 시나리오 (Given-When-Then)

1. **담당자 변경 성공** — Given 연결된 사용자가 할당 DM의 `담당자 변경` 버튼 클릭, When 모달의 `users_select`에서 (Atlas 연결된) Slack 사용자를 고르고 제출, Then 이슈 담당자가 배정되고 모달이 닫히며 `ASSIGN`/`SUCCESS` 감사 기록.
2. **담당자 대상 미연결** — Given 모달에서 Atlas 미연결 Slack 사용자를 선택, When 제출, Then 모달이 닫히지 않고 입력 블록에 "선택한 사용자가 Atlas에 연결되어 있지 않습니다" 표기(`response_action: errors`) + `ASSIGN`/`ERROR` 감사.
3. **담당자 변경 무권한** — Given 연결된 사용자가 배정 권한 없는 이슈에 제출, When `IssueMutationPort.assign`이 `IssueMutationPermissionDeniedException`, Then 모달에 "권한이 없습니다" 표기 + `ASSIGN`/`PERMISSION_DENIED` 감사.
4. **코멘트 성공** — Given 연결된 사용자가 `코멘트` 버튼 클릭 → 모달에 본문 입력 → 제출, Then 이슈에 댓글 추가 + 모달 닫힘 + `COMMENT`/`SUCCESS` 감사.
5. **코멘트 무권한** — Given 댓글 권한 없는 이슈에 제출, When 포트가 권한 예외, Then 모달에 "권한이 없습니다" + `COMMENT`/`PERMISSION_DENIED` 감사.
6. **코멘트 빈 본문** — Given 본문 미입력 제출 시도, Then Slack `input` 블록 required가 제출 자체를 차단(서버 왕복 없음).
7. **actor 미연결 (모달 열기 전)** — Given Atlas 미연결 Slack 사용자가 `담당자 변경`/`코멘트` 버튼 클릭, When block_actions 수신, Then `response_url` ephemeral "계정 연결 필요" 안내 + `ASSIGN`|`COMMENT`/`UNMAPPED` 감사(모달 안 엶).
8. **봇 미설치 / trigger_id 만료** — Given 버튼 클릭했으나 봇 토큰 없음 또는 trigger_id 부재, Then ephemeral 일반 오류 + `ERROR` 감사.

## 기능 요구사항 (FR)

- **A. 담당자 변경** — `renderAssignmentActionsMessage` DM에 `담당자 변경` 버튼(action_id `atlas_assign`, value=issueKey) 추가. block_actions → actor 역매핑(fail-closed) → 봇토큰/trigger_id 게이트 → `users_select` 모달(callback_id `atlas_assign_modal`) 오픈. view_submission → actor 역매핑 + 선택 Slack 사용자 역매핑(대상) → `IssueMutationPort.assign(AssignCommand(actor=btsActor, issueKey, assigneeId=btsAssignee, dryRun=false))` → `ASSIGN` 감사.
- **B. 코멘트** — DM에 `코멘트` 버튼(action_id `atlas_comment`, value=issueKey) 추가. block_actions → actor 역매핑 → 봇토큰/trigger_id 게이트 → `plain_text_input(multiline)` 모달(callback_id `atlas_comment_modal`) 오픈. view_submission → actor 역매핑 + 본문 추출 → `IssueMutationPort.addComment(AddCommentCommand(actor=btsActor, issueKey, body, dryRun=false))` → `COMMENT` 감사.
- **재사용** — `POST /slack/interactions` 엔드포인트·Slack 서명검증·역매핑 actor·best-effort 감사·타입예외 분류(catch 순서)·`InteractionResult` 계약 전부 PR1 그대로.

## 비기능 요구사항 (NFR)

- **전부 동기** — trigger_id 3초 만료, view_submission이 모달 닫기/errors를 결정하는 동기 계약. @Async 없음.
- **fail-closed** — 역매핑 null(actor)·무권한·대상 미연결은 안전 거부. 판정 불가는 거부.
- **내부사정 미노출** — 이슈 존재/제목/담당자 등을 응답에 드러내지 않고 일반 메시지로 치환.
- **BC 격리** — cross-BC 쓰기는 `IssueMutationPort`만 경유. issue-tracking 직접 import 금지.
- **마이그레이션 0** — V703 재사용(action_type ASSIGN/COMMENT는 이미 원문 허용). V703 편집 금지(Flyway 체크섬 드리프트).

## API 인터페이스 (REST)

- **신규 엔드포인트 없음.** 기존 `POST /slack/interactions`가 처리.
- 신규 action_id: `atlas_assign`, `atlas_comment`. 신규 callback_id: `atlas_assign_modal`, `atlas_comment_modal`.
- 신규 block_id/action_id(모달 내부): `assignee_block`/`assignee_select`, `comment_block`/`comment_input`.

## 데이터 모델 변경

- **없음.** `slack_interaction_log`(V703)에 `action_type ∈ {ASSIGN, COMMENT}`, `outcome ∈` 기존 5종만 기록.

## 엣지 케이스

- **대상 미연결(assign)** → `response_action: errors` + `ERROR` 감사(신규 outcome 값 금지 — V703 주석 정합·편집 불가라 ERROR로 수렴, 로그 메시지로 구분).
- **담당자 해제(unassign)** → PR2 범위 밖. `users_select`는 non-null 선택을 요구(input required). 해제는 후속 FR 후보(§후속).
- **코멘트 본문 초과 길이** → 포트가 검증 실패 예외 → `ERROR`. 모달 `max_length` 사전 차단은 선택(issue-tracking 댓글 상한과 정합 시).
- **view_submission엔 response_url 없음** → 성공=모달 닫기(`AckEmpty`), 실패=`response_action: errors`. **장식용 chat.update 없음** — 완료(종료 전환)와 달리 담당자/코멘트는 비종료·반복 가능 액션이라 원본 메시지를 갱신하지 않고 버튼을 유지한다.
- **모달 열기 전 사전 권한 조회 없음** — 완료는 모달 콘텐츠(resolution/done 전환)를 이슈에서 파생하느라 `getCompletionOptions` 사전조회가 필수였지만, 담당자(users_select=워크스페이스 전역)·코멘트(자유 텍스트) 모달은 이슈 파생 옵션이 없어 사전조회가 불필요하다. 권한은 submit 시 포트가 강제(무권한→PERMISSION_DENIED). 이슈키 노출 우려 없음(DM은 이미 수신자에게 발송된 이슈).
- **OCC 없음** — `AssignCommand`/`AddCommentCommand`에 expectedVersion 필드 없음(포트 계약). 따라서 PR2에 `CONFLICT` outcome은 발생하지 않는다(완료 전용).

## 제약 조건
