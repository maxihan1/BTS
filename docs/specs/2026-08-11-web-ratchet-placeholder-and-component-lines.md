## 사용자 시나리오 (Given-When-Then)

여기서 「사용자」는 이 저장소에 코드를 쓰는 **개발자/에이전트**다.

### R3 — placeholder

**S1. 신규 하드코딩 차단 (래칫의 본래 목적)**
- **Given** 개발자가 새 폼에 `placeholder="이름을 입력하세요"` 를 쓴다
- **When** `pnpm lint`(CI 포함)가 돈다
- **Then** `no-restricted-syntax` 가 **error** 로 막고, i18n 모듈을 쓰라는 한국어 메시지를 준다

**S2. 템플릿 리터럴 우회 차단**
- **Given** ``placeholder={`${x} 검색`}`` 처럼 백틱으로 쓴다
- **When** lint
- **Then** `TemplateElement` 선택자가 막는다 (`Literal` 선택자만으로는 뚫린다)

**S3. 프리미티브 레이어도 예외 아님**
- **Given** `src/components/ui/**` 에 새 한글 placeholder 를 쓴다
- **When** lint
- **Then** 막힌다. **비-테스트 히트가 실측 0건**이라 예외 없이 처음부터 편입할 수 있다
  (정본은 「뚫린 채로 시작한다」고 경고했으나 실측이 그 전제를 해제했다)

**S4. button 예외 파일도 예외 아님**
- **Given** `DashboardForm.tsx`(원시 `<button>` 예외 파일)에 새 한글 placeholder 를 쓴다
- **When** lint
- **Then** 막힌다. 이 파일은 `no-restricted-syntax` 를 **대체**하는 블록에 있어서, 그 블록을 안 고치면 영구 면제된다

**S5. 규칙이 죽으면 즉시 red (비-공허)**
- **Given** 누군가 선택자를 오타 내거나 규칙 항목을 지운다
- **When** `pnpm test`
- **Then** **양성 대조군**(한글 placeholder 를 담은 가상 소스)이 「막혀야 할 것이 안 막혔다」로 red

**R3-FR3 상세 — 어느 블록을 어떻게 고치나 (실측 기반).**

> **★먼저 정본을 정정한다 (2026-08-11 `--print-config` 실측).**
> 정본은 「이 규칙은 **병합이 아니라 대체**된다」고 한 문장으로 적었으나, **그건 배열 지정에만 참이다.**
>
> | 뒤 블록이 쓴 형태 | 실제 동작 | 실측 |

> | **배열** (`['error', {…}]`) | **완전 대체** — 앞 블록 셀렉터가 사라진다 | `DashboardForm.tsx` → `severity 2 · 셀렉터 1개(animate-pulse만)`. button 셀렉터 소실 확인 |

**R4-FR3 상세 — 왜 파일명만으로는 안 되나.**
`ImportMappingWizard.tsx:782` 는 `export const ImportMappingWizard = (…): JSX.Element =>` 라
ESLint 가 이름 없이 **「Arrow function」** 으로 보고한다. 함수명 기준 키는 이 항목을 식별하지 못한다.
현재 **18건이 18파일에 1:1** 이라 파일 단위로도 유일하지만, 그것은 우연이다.
⇒ 키를 `파일::서술자`로 두고, **같은 키가 2번 나오면 즉시 red** 로 충돌을 드러낸다.
경로는 **`apps/web` 기준 상대 경로**여야 한다 — worktree·CI·main 트리의 절대 경로가 다르다 (G9).

**R4-FR4 상세 — 단조 래칫이 남기는 느슨함 (G4, 의도적 수용).**
`1041 → 900` 은 green 이고 베이스라인은 1041 로 남는다. 그래서 **900 → 1041 로 되돌아가는 것도 green** 이다.
이 느슨함을 아는 채로 수용한다 — **개선이 red 를 만들면 아무도 개선하지 않는다.**
대안 「엄격 일치(`toEqual`)」는 그 18개 함수를 **한 줄만 고쳐도** 베이스라인을 갱신하게 만들고,

⇒ 베이스라인 파일에 「줄인 뒤에는 이 숫자를 함께 낮춰라」를 주석으로 남긴다.
