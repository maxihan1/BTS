# FR-RP-01 D6/D7 — 번다운/번업 차트 프론트 UI — 스펙

> slug: fr-rp-01-d6-d7-ui · type: ui · BC: agile-planning · 백엔드 #219 연장

## 결정 (Maxi 확정 2026-07-02)

- **배치**. 전용 라우트 `/projects/$projectKey/sprints/$sprintId/burndown` (TanStack Router). 진입점. 백로그 페이지 `SprintColumn`의 "번다운" 버튼.
- **구성**. 단일 차트 + **번다운/번업 토글**. 기본=번다운.
  - 번다운. `remaining`(잔여, 하강) + `ideal`(기준 직선) + `scope`(평탄 상한).
  - 번업. `completed`(완료, 상승) + `scope`(평탄 상한).
- **선례 재사용**. `components/worklog/WorklogAggregateChart.tsx`(recharts·ResponsiveContainer·고정높이·순수변환 named export·`formatSeconds`·i18n 라벨).

## 사용자 시나리오 (Given-When-Then)

- **S1**. Given 활성 스프린트(시작·종료일 설정됨), When 백로그에서 스프린트 칸 "번다운" 클릭, Then 전용 라우트로 이동해 잔여+ideal+scope 라인 차트를 본다.
- **S2**. Given 번다운 화면, When "번업" 토글, Then 같은 차트가 완료(상승)+scope 로 전환된다.
- **S3**. Given 시작일/종료일 미설정 스프린트, When 번다운 진입, Then 백엔드 422 → "스프린트 시작일과 종료일을 설정해야 번다운을 볼 수 있습니다" 안내(차트 대신).
- **S4**. Given 스프린트 진행 중(오늘 < 종료일), When 차트 표시, Then 실제선(잔여/완료)은 오늘까지만 그려지고 이후는 끊긴다(미래 null). ideal/scope 는 전 구간 그려진다.
- **S5**. Given 볼 권한 없음(프로젝트 BROWSE 없음), When 진입, Then 403 → "접근 권한이 없습니다" 안내. 없는 스프린트 → 404 안내.

## 기능 요구사항 (FR)

- **FR1**. `GET /api/v1/sprints/{id}/burndown` 조회 (TanStack Query + Zod 파싱). queryKey=`['sprint-burndown', sprintId]`.
- **FR2**. 번다운/번업 토글 → **URL search param** `?view=burndown|burnup`(기본 burndown). TanStack Router search 검증(zod). 이유. 전용 라우트를 고른 근거가 "공유 URL"이므로 번업 뷰도 URL 로 공유·딥링크 가능해야 정합(brainstorming 발견).
- **FR3**. Y축=초를 시간으로 표시(`formatSeconds` 틱 포매터). X축=날짜(startDate..endDate).
- **FR4**. 실제선(잔여/완료) 미래 구간 null → `connectNulls={false}` 로 끊김. ideal/scope 전 구간.
- **FR5**. 툴팁. 날짜 + 해당 시리즈 값(시간 표기).
- **FR6**. SprintColumn 에 "번다운" 진입 버튼(라우트 링크). 모든 상태 노출(데이터 없으면 422/빈 안내).
- **FR7**. 상태별 화면. 로딩(스켈레톤/스피너) · 에러(일반) · 403/404/422 각각 안내 메시지.

## 비기능 요구사항 (NFR)

- **NFR1**. recharts 는 jsdom 에서 width 0 → 렌더 안 됨. **차트 데이터 변환은 순수 함수로 분리**해 단위 테스트, 실제 렌더는 실브라우저 E2E(FR-TT-02 선례).
- **NFR2**. 백엔드 nullable(`remainingSeconds`/`completedSeconds`) → Zod `.nullish()`.
- **NFR3**. MSW 핸들러 응답이 `BurndownResponse` 계약과 정확히 일치(계약 drift 금지, 적대 리뷰 표면화 선례).
- **NFR4**. i18n 라벨 문자열은 문장 끝 콜론 금지(글로벌 §5·i18n 콜론 선례).
- **NFR5**. 인증된 fetch 는 `apiFetch` 사용(로그인 전 raw fetch 예외 아님 — 이 화면은 인증 후).

## API 인터페이스 (백엔드 #219, 프론트 소비)

```
GET /api/v1/sprints/{sprintId}/burndown  →  200 { data: BurndownResponse }
BurndownResponse:
  sprintId: string(uuid), projectKey: string, status: SprintStatus,
  startDate: "YYYY-MM-DD", endDate: "YYYY-MM-DD", totalScopeSeconds: number,
  points: BurndownPointResponse[]
BurndownPointResponse:
  date: "YYYY-MM-DD", remainingSeconds: number|null, idealSeconds: number,
  completedSeconds: number|null, scopeSeconds: number
에러: 401 / 403(권한) / 404(스프린트 없음) / 422(AGILE_SPRINT_DATES_REQUIRED)
```

## 엣지 케이스

- E1. 미래 날짜 point → remaining/completed null → 실제선 끊김(ideal/scope 유지).
- E2. worklog 0 스프린트 → 잔여 평탄(=scope), 완료 0.
- E3. 1일 스프린트 → point 1~2건, ideal 단조.
- E4. 422 dates-required → 차트 대신 안내(시작·종료일 설정 유도).
- E5. points 빈 배열(방어) → "표시할 데이터가 없습니다" 안내.
- E6. 매우 큰 값(시간) → Y축 시간 표기로 자릿수 관리(`formatSeconds`).
