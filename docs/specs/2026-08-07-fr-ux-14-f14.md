## 1. Jira 대조 (계약 §1 절차 산출물)

**① 대응 화면.** Jira Cloud 2025 의 보드(칸반) 카드 · 백로그 행.

**② 조작감 갭.**

| 갭 | Jira Cloud | BTS 현재 |
|---|---|---|
| 유형 식별 | 카드 하단 좌측에 유형 아이콘 상시 노출 | **없음** — 카드를 열어야 종류를 안다 |
| 라벨 | 제목 아래 칩 행 (설정 시), 넘치면 접힘 | **없음** |
| 추정 | 하단 우측에 배지 (story point / 시간) | **없음** |
| 우선순위 | 하단 우측 아이콘 | 백로그만 `P{n}` 칩, 보드는 없음 (**범위 밖 — 이번에 건드리지 않는다**) |

**③ BTS 제약과 교차** (계약 §2 즉사 계약).

- 카드 `aria-label` = `` `${issueKey} — ${summary}` `` 와 `aria-roledescription="draggable card"` 는
  **문자열 그대로 보존**한다. E2E 5스펙이 이 두 개로 카드를 찾는다
  (`board-reorder` · `board-filter` · `board-kanban` · `board-swimlane-field-change` · `quick-filter`).
  → **새 요소는 카드 내부에 넣되 카드 루트 요소의 속성은 한 글자도 바꾸지 않는다.**
- `<h1>` · 네비 `aria-label` 4종 · 단축키 레지스트리 — 이 작업이 건드리지 않는다.
- 신규 텍스트가 기존 E2E 의 전역 셀렉터와 충돌하지 않아야 한다(learnings.md:631 — D6 이
  '저장' 버튼을 늘려 기존 E2E 를 strict mode violation 으로 깬 선례).

**④ 결정.** Jira 대응 화면이 **있으므로** ADS 준용이 아니라 **Jira 배치를 그대로 따른다**
(Maxi 확정 2026-08-07, D1 = A안).

```
┌──────────────────────────────┐
│ 결제 실패 시 재시도 로직 추가  │  ← 제목 (line-clamp-2, 기존 그대로)
│                              │
│ [결제] [urgent] +2           │  ← 라벨 칩 행 — labels.length > 0 일 때만 생성
│                              │
│ 🐞 ATLAS-142   2h 30m   (김) │  ← 유형아이콘·키 … 추정배지·담당자
└──────────────────────────────┘
```

**라벨이 없는 카드는 칩 행 자체가 생기지 않아 높이가 현재와 동일하다** — 밀도 손해 0.

## 2. 사용자 시나리오 (Given-When-Then)

**S1. 유형을 카드에서 바로 안다**
Given 보드에 버그 1건과 작업 1건이 있고
When 사용자가 보드를 연다
Then 각 카드 하단 좌측에 유형 아이콘(버그=`Bug`, 작업=`CheckSquare`)이 이슈 키 왼쪽에 보이고,
스크린리더는 그 아이콘을 **유형 표시 이름**(예. "버그")으로 읽는다.

**S2. 라벨이 칩으로 보인다**
Given 이슈에 라벨 `["결제", "urgent"]` 가 있고
When 보드/백로그를 연다
Then 제목 아래에 칩 2개가 순서대로 보인다.

**S3. 라벨이 없으면 자리도 없다**
Given 이슈에 라벨이 하나도 없고(`labels: []`)
When 보드/백로그를 연다
Then 라벨 칩 행이 **DOM 에 생성되지 않고** 카드 높이가 이전과 같다.

**S4. 라벨이 많으면 접힌다**
Given 이슈에 라벨이 5개 있고
When 보드/백로그를 연다
Then 앞 3개만 칩으로 보이고 `+2` 오버플로 칩이 뒤따르며, 그 칩은 전체 라벨을 `title` 로 갖는다.

**S5. 추정이 시간 표기로 보인다**
Given 이슈의 `originalEstimateSeconds` 가 `9000` 이고
When 보드/백로그를 연다
Then 하단 우측 담당자 왼쪽에 `2h 30m` 배지가 보인다.

**S6. 추정이 없으면 자리도 없다**
Given `originalEstimateSeconds` 가 `null` 이고
When 보드/백로그를 연다
Then 추정 배지가 **DOM 에 생성되지 않는다**(`0m` 을 그리지 않는다).

**S7. 알 수 없는 유형도 카드를 깨뜨리지 않는다**
Given 카드의 `typeKey` 가 유형 목록 응답에 없고(커스텀 유형 · 목록 로딩 중)
When 보드/백로그를 연다
Then `Circle` fallback 아이콘이 보이고 접근성 이름은 **`typeKey` 원문**이 되며 카드는 정상 렌더된다.

**S8. 기존 조작이 그대로다**
Given 카드에 3요소가 모두 추가된 상태에서
When 사용자가 카드를 드래그하거나 제목을 클릭한다
Then 드래그 순서변경과 이슈 상세 이동이 이전과 동일하게 동작한다.

## 3. 기능 요구사항 (FR)

| ID | 내용 |
|---|---|
| **FR1** | `boardCardSchema` 에 `typeKey: z.string().min(1)` · `labels: z.array(z.string())` · `originalEstimateSeconds: z.number().int().nullable()` 를 **전부 필수 키로** 추가한다. `.default()` · `.optional()` · `.catch()` 를 쓰지 않는다 (Maxi 확정 2026-08-07, D2 = A안) |
| **FR2** | `backlogIssueSchema` 에 FR1 과 **동일한 3필드를 동일한 강도로** 추가한다 |
| **FR3** | `BoardCard` 는 `typeIconName: string \| null` · `typeName: string` 두 **원시 prop** 을 받는다. 객체 prop 을 받지 않는다 — `memo` 비교가 매 렌더 깨진다 |
| **FR4** | `BacklogCard` 는 FR3 과 동일한 두 prop 을 받는다 |
| **FR5** | 유형 해석(`typeKey` → `{iconName, name}`)은 **카드가 아니라 상위**가 한다. `useIssueTypes()` 를 카드마다 호출하지 않는다 (카드 수십 개 × 훅) |
| **FR6** | 유형 미해석 시 `typeIconName = null` · `typeName = typeKey` **원문**으로 넘긴다. 빈 문자열이나 '알 수 없음' 같은 조용한 문구로 덮지 않는다 |
| **FR7** | 하단 행 좌측은 `[IssueTypeIcon][issueKey]` 순서, 우측은 `[추정 배지][담당자]` 순서다. 백로그는 기존 `P{priority}` 칩을 **추정 배지 왼쪽에** 유지한다 |
| **FR8** | 라벨 칩은 `Badge` 프리미티브(variant `neutral`)로 그리고 **최대 3개** 표시한다. 4개 이상이면 `+N` 오버플로 칩 1개를 덧붙인다 |
| **FR15** | 오버플로 칩의 **접근성 이름에 숨은 라벨 전문**을 담는다(`라벨 2개 더 — d, e`). `title` 은 마우스 보조로만 남긴다 — `title` 은 터치 화면에서 뜨지 않아 그것만으로는 태블릿·폰 사용자가 접힌 라벨을 영영 볼 수 없다 (Maxi 확정 2026-08-07 D6) |
| **FR16** | 라벨 칩 글자색은 `text-muted-foreground` 다. `Badge` 기본(`text-foreground`)은 카드 제목과 같은 무게라 시선을 뺏는다. **프리미티브를 고치지 않고 `className` 으로만 낮춘다** — 다른 화면의 `Badge` 에 영향 0 (Maxi 확정 2026-08-07 D5) |
| **FR17** | 새 요소의 라운드는 `DESIGN.md §7` 명시 스케일(`rounded-sm` 3px)을 쓴다. 맨 `rounded` 는 그 5단계 표에 없는 **off-scale 값**이라 기존 `P{priority}` 칩에서 베끼지 않고, 같은 행에 두 라운드가 섞이지 않도록 그 칩도 함께 정렬한다 |
| **FR9** | `labels.length === 0` 이면 라벨 칩 컨테이너를 **렌더하지 않는다**(빈 `div` 도 만들지 않는다) |
| **FR10** | `originalEstimateSeconds === null` 이면 추정 배지를 **렌더하지 않는다** |
| **FR11** | 추정 표시 문자열은 `lib/duration.ts` 의 `formatSeconds()` 결과 그대로 쓴다. 새 포맷터를 만들지 않는다 |
| **FR12** | 새 사용자 노출 문자열(추정 접근성 레이블 · 라벨 오버플로 레이블)은 `i18n/board-labels.ts` · `i18n/backlog-labels.ts` 에 넣는다. 컴포넌트에 인라인 리터럴로 두지 않는다 |
| **FR13** | 카드 루트 요소의 `aria-label` · `aria-roledescription` · `data-*` 속성을 **한 글자도 바꾸지 않는다** (계약 §2) |
| **FR14** | 3필드를 필수로 만들면서 깨지는 기존 테스트 데이터 생성 지점을 **전수 보강**한다. `tsc --noEmit` 이 뽑은 목록이 정본이고, 사람이 grep 한 목록을 정본으로 쓰지 않는다 |
