## Brief

FR-UX-05 키보드 단축키 구현. FR-UX-04(Cmd+K 팔레트)와 인접한 프론트 전용 기능.

기본 단축키 매핑(SDD 20.9, Gmail/Linear 스타일 참조):
- `?` — 단축키 도움말
- `c` — 이슈 생성
- `g i` — 내 이슈
- `g d` — 대시보드
- `/` — 검색
- `j / k` — 다음/이전 (보드, 리스트)
- `e` — 편집
- `m` — 담당자 변경
- `s` — 상태 변경
- `cmd+k` — Command Palette (FR-UX-04에서 이미 구현)

구현: react-hotkeys-hook + 도움말 모달(`?`).

백엔드 D3~D5 해당 없음(product §4.3). 커스터마이즈(FR-PF-03, `user_keymap` 테이블)는 별도 FR로 이 작업 범위 밖.

classify: type=ui, agent=frontend-engineer (primary_bc는 agile-planning으로 오판→personalization 정정).
