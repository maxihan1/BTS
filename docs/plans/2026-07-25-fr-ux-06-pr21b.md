## Brief

칸반 보드에서 카드를 **다른 스윔레인 그룹(줄)**으로 드래그하면 해당 필드가 변경되는 기능.
PR21(같은 셀 내 순서변경 rank + 컬럼 간 상태전이)에 이어 완전 Jira 스윔레인 드래그 4종을 완성.

- ③ 담당자 스윔레인 다른 행 = 담당자 재할당 (`PATCH /issues/{key}/assignee`)
- ④ 우선순위 스윔레인 다른 행 = 우선순위 변경 (`updateIssue priority`)
- ④ 에픽 스윔레인 다른 행 = 에픽 재배치 (`POST epic-children`)

★ ASSIGNEE 그룹 key가 이름 기반(`assignee-named-{이름}`)이라 담당자 UUID 역산 배선 필요.
낙관적 업데이트 3종(성공 반영·409/실패 롤백+toast).

**classify 정정**: classify-task가 backend/agile-planning으로 오분류. 실측 = 순수 프론트
드래그 상호작용. API 3종 모두 실재(백엔드 신규 0 예상). FR-UX-06 주 BC=personalization.
PR9/PR10/PR12 동일 오분류 선례.
