### 백엔드 계약 (grep 실재 확인 — invent 금지)

API는 **프로젝트 스코프** (`AutomationRuleController`, `@RequestMapping("/api/v1/projects/{projectKey}/automation/rules")`). MANAGE_AUTOMATION = PROJECT_ADMIN → slack 같은 전역 `/admin/*` 아님. 5 엔드포인트.

| 메서드 | 경로 | 응답 | 비고 |
|---|---|---|---|
| POST | `.../rules` | 201 `CreateAutomationRuleResponse` | WEBHOOK이면 `webhookToken` 원문 **1회** 동봉 |
| GET | `.../rules` | 200 `List<AutomationRuleResponse>` | 목록 |
| GET | `.../rules/{id}` | 200 `AutomationRuleResponse` | 토큰 미노출 |
| PATCH | `.../rules/{id}` | 200 `AutomationRuleResponse` | name·enabled·triggerConfig (OCC, `version` 필수) |
| DELETE | `.../rules/{id}` | 204 | soft delete |

**요청 DTO** — `CreateAutomationRuleRequest { name, triggerType(enum), triggerConfig("{}" 기본) }` · `PatchAutomationRuleRequest { version(필수), name?, enabled?, triggerConfig? }`.
**응답 DTO** — `AutomationRuleResponse { id, projectKey, name, enabled, triggerType, triggerConfig(JSON 문자열), hasWebhookToken, nextFireAt?, createdBy, createdAt, updatedAt, version }`. 토큰 원문/해시 필드 아예 없음(타입상 누출 차단). `CreateAutomationRuleResponse { rule, webhookToken? }`.
**에러코드** — 401 `AUTOMATION_UNAUTHENTICATED` · 403 `AUTOMATION_ACCESS_DENIED` · 404 `AUTOMATION_RULE_NOT_FOUND` · 409 `AUTOMATION_RULE_VERSION_CONFLICT`(OCC) · 400 `AUTOMATION_RULE_INVALID`/`AUTOMATION_MALFORMED_REQUEST`. RFC 7807 ProblemDetail(`errorCode` 프로퍼티).

### 트리거 타입 5종 + triggerConfig 형식 (폼 필드 결정 근거)

`TriggerConfig.validate` 기준.
- **ISSUE_CREATED / ISSUE_COMMENTED** — 빈 config `{}` (설정 없음)
- **ISSUE_UPDATED** — `{ fields?: string[] }` (선택. 특정 필드 변경 시만 발화)
- **SCHEDULED** — `{ cron: string }` (필수, Spring `CronExpression` 6필드 파싱)
- **WEBHOOK** — `{}` (생성 시 불투명 토큰 1회 발급)

### 프론트 현황 / 배치

- 프론트에 **automation 코드 0, MANAGE_AUTOMATION 권한코드 0** → 그린필드.
- 배치 후보: **`projects.$projectKey.settings.automation.tsx`** (workflow-scheme·field-permissions와 동열 관리자 설정). RouteAdapter + Page 분리 패턴([[TanStack Router code-based]]) 재사용.
- api 레이어: `apps/web/src/api/automation-rules.ts` (+ `.types.ts` + test), MSW `mocks/automation-rule-handlers.ts`.

### 스펙 게이트에서 결정할 UX (spec 단계로 이월)

1. **스코프 확인** — FR-AT-01 D6 = **트리거 선택만** (name·트리거·config·enabled). 액션(FR-AT-02)/조건(FR-AT-03) 빌더는 별개 FR, 미구현. ⚠️ 트리거만 있는 룰은 `q_automation_execution` enqueue만 하고 실제 동작 없음(FR-AT-02 executor 부재) → "지금 만들 가치" 확인 필요.
2. 페이지 배치 (settings 탭 vs 별도).
3. WEBHOOK 토큰 1회 노출 UX (생성 후 모달 + 복사).
4. SCHEDULED cron 입력 (자유입력 6필드 vs 프리셋).
5. ISSUE_UPDATED fields 입력 (자유 vs 필드 목록).
