## Brief

**classify**. type=auth, agent=security-engineer, primary_bc=identity-access, slug=fr-mf-05-d6-d7-ui-e2e.

**컨텍스트**. 백엔드 D1~D5는 PR #131로 완료. 본 작업은 프론트 전용(apps/web), 백엔드 변경 0(계약 소비). 선행 FR-MF-01~04 D6/D7과 동형 분할.

**백엔드 계약 요약**(PR #131, product §3.5).
- MFA verify 성공 + `trust_device=true` 동의 → `Set-Cookie trusted_device`(HttpOnly·Secure·SameSite=Strict·Path=/api/v1/auth·30일). DB는 SHA-256 token_hash만.
- 다음 로그인 시 `completeLogin`이 쿠키를 `verifyAndTouch` 검증 → 챌린지 생략. 실패 시 기존 `mfa_required` 폴백(fail-safe).
- 클라이언트 핑거프린트 기각(서버 불투명 토큰).
- 취소 = 수동(`GET` 목록 / `DELETE {id}`(IDOR 404) / `DELETE` 전체, JWT 전용·PAT 403) + 자동(비번변경·TOTP 비활성 시 revokeAll).
- 고정 30일(sliding 아님). 감사 TRUSTED_DEVICE_ADDED / REVOKED.

- **영향 엔티티**. `TrustedDevice`(백엔드 기존, #131). 프론트는 계약 소비만 — 신규 도메인/엔티티 0, 백엔드 변경 0.

- **기존 결정 충돌**. 없음. ADR `2026-06-13-trusted-device-mfa-exemption` 재확인 — D6/D7은 그 계약을 프론트로 노출하는 작업.
- **관련 ADR**. [docs/decisions/2026-06-13-trusted-device-mfa-exemption.md](../decisions/2026-06-13-trusted-device-mfa-exemption.md) (기존, 신규 ADR 생성 없음 — 선행 FR-MF D6/D7 동형).

### 소비할 백엔드 계약 (ground-truth, AuthController/TrustedDeviceController 실측)

| 용도 | 메서드 · 경로 | 응답 |
|---|---|---|
| 목록 | `GET /api/v1/auth/mfa/trusted-devices` | 200 `{devices:[{id:UUID, label:string?, createdAt:Instant, lastUsedAt:Instant?, expiresAt:Instant}]}` |
| 단건 취소 | `DELETE /api/v1/auth/mfa/trusted-devices/{id}` | 204 / 404 `{error:"not_found"}` / 403 `{error:"session_management_requires_interactive_login"}` / 401 |
| 전체 취소 | `DELETE /api/v1/auth/mfa/trusted-devices` | 204 (멱등) |
| 신뢰 동의 | `POST /api/v1/auth/mfa/verify` body에 `trust_device: boolean`(기본 false) | 성공 시 trusted_device 쿠키 발급, 응답 body는 기존 `TokenResponse` 그대로 |

- **PAT 차단**. 목록/취소는 JWT 전용(PAT는 403). 프론트는 대화형 세션이라 항상 JWT.
- **계약 주의**. `label` nullable, `lastUsedAt` nullable(미사용 시 null). 시각은 ISO Instant 문자열(직렬화 키 camelCase: createdAt/lastUsedAt/expiresAt).
