## Brief

FR-SR-04(한글 형태소 기반 전문 검색)의 프론트 후속. 백엔드 D1~D5는 #195로 완료
(AQL 신규 `text` 가상 필드 — `~` 전용, summary+description 전문 검색 / V032 search_vector
generated column + GIN + trigram 인덱스). D6/D7만 남음.

- D6. 프론트 UI — FR-SR-02에서 만든 AQL 검색창 syntax highlight 토크나이저에
  `text` 키워드 강조 추가. (책임. frontend-engineer)
- D7. E2E — `text` 키워드 검색 시나리오. (책임. qa-engineer)

classify가 "E2E" 키워드로 qa 오판 → ui/frontend-engineer 정정
(메모리 fr-ux-02/fr-sr-02 동일 학습).

## 도메인 정리

- **BC**: search-export-import(논리) / issue-tracking(물리). FR-SR 시리즈 패턴 계승.
  새 BC·엔티티·관계 없음. 순수 프론트엔드 작업(검색창 토크나이저 + E2E).
- **영향 파일**:
  - `apps/web/src/lib/aql-tokenizer.ts` — `AQL_FIELDS` 화이트리스트 (현 누락 대상)
  - `apps/web/src/components/search/AqlHighlighter.tsx` — 토큰→색 매핑(FIELD 색 재사용)
  - 각 `.test.ts(x)` + E2E `apps/web/e2e/`
- **계약 drift 발견(핵심)**: 프론트 `AQL_FIELDS = [status, label, summary, priority]` ↔
  백엔드 정본 `AqlFields.MVP_FIELDS = {status, label, summary, priority, **text**}`.
  백엔드가 #195(FR-SR-04 D4)에서 `text` 가상 필드를 추가했으나 프론트 하이라이터는
  미반영 → `text ~ "검색어"` 입력 시 `text`가 PLAIN으로 처리돼 강조 안 됨.
  → D6 = `AQL_FIELDS`에 `'text'` 추가(백엔드 정본과 동기화).
- **백엔드 `text` 필드 계약**(검증된 사실):
  - 가상 FTS 필드(실제 DB 컬럼 아님, `issues.search_vector` 경유 tsvector+trigram 하이브리드)
  - `~`(CONTAINS) 전용. `=`/`!=`/`in`/`not in` 금지(`AqlFields.isOperatorForbidden`)
  - 대소문자 무시(`classify("TEXT") == SUPPORTED`)
  - ORDER BY 정렬 불가(`SORTABLE_FIELDS`에 미포함, `ORDER BY text` → 400 SEARCH_UNKNOWN_FIELD)
- **새 용어**: "text 가상 필드"(AQL FTS 검색 진입점). glossary에 FTS·AQL 항목 존재 →
  사소한 보강 후보, plan에 기록(머지 단계 Obsidian sync에서 반영 검토).
- **기존 결정 충돌**: 없음. ADR [2026-06-26-fr-sr-04-korean-fts.md](../decisions/2026-06-26-fr-sr-04-korean-fts.md)
  D4가 정확히 이 프론트 통합을 예약("검색창 동일·같은 보안 술어"). 충돌이 아니라 **이행**.
- **관련 ADR**: 위 FR-SR-04 ADR(기존). 신규 ADR 불필요.
- **classify 정정**: "E2E" 키워드로 qa 오판 → ui/frontend-engineer(메모리 fr-ux-02/fr-sr-02 동일 학습).

## 스펙

전체 스펙. [docs/specs/2026-06-27-fr-sr-04-d6-d7.md](../specs/2026-06-27-fr-sr-04-d6-d7.md)

핵심 3줄.
- `aql-tokenizer.ts`의 `AQL_FIELDS`에 `'text'` 추가 → `text ~ "검색어"`의 `text`가 FIELD 색 강조(백엔드 MVP_FIELDS 정합).
- 기존 `text-syntax-field` 색 재사용. 신규 토큰 타입·색·디자인 변형 없음.
- (선택) placeholder에 `text ~ "키워드"` 전문 검색 예시 추가(발견성). D7 E2E로 강조+검색 검증.
