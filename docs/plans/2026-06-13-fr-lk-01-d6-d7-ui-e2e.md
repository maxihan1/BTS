### 백엔드 API 계약 (PR #135, 박제 — 재발굴 금지)

베이스: `/api/v1/issues/{key}`. 응답은 모두 `DataResponse<T>` = `{ data: T }` 래퍼.

1. `POST /links` → 201
   - req `{ targetKey: string, linkType: string(소문자 "blocks"/"relates"/"duplicates"/"clones") }`
   - res `data: IssueLinkResponse`
2. `GET /links` → 200
   - res `data: { outward: IssueLinkResponse[], inward: IssueLinkResponse[] }`
3. `DELETE /links/{linkId}` → 204 (linkId = number/BIGINT)
4. `PATCH /parent` → 200
   - req `{ parentKey: string | null }` (null = 해제)
   - res `data: { key: string, parent?: { key: string, summary: string } }`
     - parent는 null이면 **JSON 키 자체 생략**(@JsonInclude NON_NULL) → Zod `.nullish()` / optional 처리 필수.

**IssueLinkResponse** = `{ id: number, linkType: string(대문자 "BLOCKS"), direction: "OUTWARD"|"INWARD", label: string, otherIssue: { key: string, summary: string, statusKey: string } }`

**에러코드**(ProblemDetail `errorCode`): ISSUE_NOT_FOUND(404), LINK_SELF_REFERENCE(422), DUPLICATE_LINK(409), LINK_CYCLE(409), LINK_NOT_FOUND(404), PARENT_SELF_REFERENCE(422), PARENT_CYCLE(409), INVALID_LINK_TYPE(400), VALIDATION_FAILED(400).

- **재사용 UI 골격**. `components/issue/VersionMultiSelect.tsx`(검색+칩+다중선택), `IssueMetaPanel.tsx:806~858`의 `IssueAssigneeSelect`(debounce 검색→`useUsers`→목록 선택) — 링크 대상 이슈 검색에 이 debounce 패턴 차용.
- **api 관례**. `api/client.ts` `apiFetch`(Authorization 자동·credentials include·CSRF 쿠키 의존·401 retry), `api/issues.ts` `dataResponseSchema`(`{data:T}` 언랩), Zod 스키마는 api 파일 내 정의.

### ⚠️ 계약 차이 (버전 링크 패턴 그대로 복사 금지)
형제 FR-VR-03(버전 링크)은 **이슈 응답에 임베드된 배열(`affectsVersionIds`)을 PATCH로 통째 교체 + `expectedVersion` OCC**. **이슈 링크는 메커니즘이 다름**.
- `GET /links` → 이슈와 **별개 쿼리**(`{outward[], inward[]}`). 자체 queryKey 필요(예: `issueLinksKey(key)`).
- 추가 = `POST /links` **단건**(`{targetKey, linkType소문자}`). 제거 = `DELETE /links/{linkId}` **단건**. **expectedVersion/OCC 없음**.
- parent = `PATCH /parent` (`{parentKey|null}`). 응답 `parent`는 null 시 키 생략(NON_NULL) → Zod `.nullish()`.
- 따라서 mutation은 "전체배열 교체"가 아니라 "단건 add/remove" + `invalidateQueries(issueLinksKey)`. linkType 코드는 요청 소문자 / 응답 대문자(`BLOCKS`)로 비대칭 — 박제 주의.

### 신규 필요 (선례 없음)
- **링크 대상 이슈 검색/선택**. 전용 컴포넌트 없음. `IssueAssigneeSelect` debounce 패턴 차용해 이슈 키/요약 검색 입력 신규. 백엔드 이슈 검색 api 존재 여부는 spec에서 확정(없으면 범위/대안 Maxi 확인).

- E2E 5 시나리오(추가/에러/제거/부모 set/clear) + 기존 이슈 상세 E2E 회귀 0.
