## Brief

FR-SL-05(Slack 인터랙티브 메시지)의 2번째이자 마지막 PR. slack-integration BC의 6번째이자 마지막 FR을 완결한다.

- **PR1(#261) 이미 머지됨** — 인바운드 인터랙티브 인프라(`POST /slack/interactions` + 서명 검증) + `완료로 표시`(resolution 선택 모달) + `상세보기`(URL) + V703 감사 마이그레이션.
- **이 PR2 범위** — 두 인터랙티브 액션 추가.
  1. **담당자 변경** — Slack `block_actions` users_select → cross-BC `IssueMutationPort.assign` 위임 → ASSIGN 감사 기록.
  2. **코멘트** — Slack `view_submission`(모달 제출) → cross-BC `IssueMutationPort.addComment` 위임 → COMMENT 감사 기록.
- PR2 완료 시 D4~D7 채워지고 slack-integration이 **5/6 → 6/6 (BC 완료)**. FR 총수 123 불변.

### 재사용 (PR1에서 이미 착지)

- 인바운드 엔드포인트 `POST /slack/interactions` + Slack 서명 검증 (신규 action_id/callback_id 분기만 추가).
- V703 감사 인프라 (ASSIGN·COMMENT 종류 레코드만 추가 기록. **V703 파일 편집 금지** — 이미 적용된 마이그레이션, 스키마 변경 필요 시 V704 신설).
- cross-BC `IssueMutationPort` (assign/addComment 메서드 존재 여부는 domain/spec에서 grep 검증).

### 착수 전 알려진 함정 (learnings + memory)

1. **★Flyway 체크섬 함정** — `:modules:app:test`(prod 조립 부팅 검증)는 Testcontainers가 아니라 영속 로컬 postgres(localhost:5433). 이미 적용된 마이그레이션(V703 등) 편집 시 체크섬 드리프트로 부팅 실패. 새 스키마는 V704.
2. **★test-boot 가짜그린** — `SlackTestcontainersConfig`의 공유 mock `MethodsClient`(relaxed)는 viewsOpen에 isOk=false 반환. 모달 API 결과 무시 시 실패 침묵. `stubSlackModalApisOk`로 ok 스텁 필요.
3. **★후처리 격리** — cross-BC 커밋 후 장식용 side-effect(chat.update)는 best-effort try로 격리.
4. **form-body @RequestParam 병용금지** (SL-04 선례) — interactions는 `payload` form-field JSON 파싱.
5. **cross-BC 권한 전량 포트 위임** — 담당자/코멘트 권한 판단은 issue-tracking 어댑터에 위임(직접 role 조회 금지).
