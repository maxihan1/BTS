### E2E 시나리오 (`e2e/project-lead.spec.ts` 신규)
- S1. **리드 지정** — alice 로그인 → settings/project-lead → "리드 검색"에 "캐럴" 입력 → 드롭다운 "캐럴" 버튼 클릭 → PATCH /lead → `lead-current-name`이 "캐럴" 표시 + 성공 토스트.
- S2. **리드 해제** — S1 상태(또는 시드된 리드)에서 "미지정" 버튼 클릭 → PATCH null → `lead-current-name` "미지정".
- S3. **권한 disabled** — bob 로그인(MANAGE_COMPONENTS false) → "리드 검색" input·미지정 버튼 disabled.
- S4. **삭제된 리드 표시** — X-MSW-Seed-ProjectLead로 user fixture에 없는 UUID 시드 → `lead-current-name` "알 수 없는 사용자 (앞8자)" + 해제 버튼 노출.
- S5. **폴백 자동배정** — 프로젝트 리드(김앨리스) 시드 + 컴포넌트 리드 없는 컴포넌트(또는 컴포넌트 미지정) 이슈 생성 → 이슈 상세 담당자 "김앨리스"(프로젝트 리드 폴백). createIssueHandler 폴백 미러 필요.
