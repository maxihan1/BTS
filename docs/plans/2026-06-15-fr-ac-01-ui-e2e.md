## Brief

FR-AC-01 첨부 기능의 D6(프론트 UI) + D7(E2E)를 구현한다.
백엔드 D1~D5는 PR #145로 완료(MinIO 서버 경유 멀티파트 스트리밍).

**deviation 반영(#145, ADR 2026-06-15-fr-ac-01-attachment-storage)**:
- plan 표기 "react-dropzone + 직접 PUT"은 stale. 실제는 **서버 경유 multipart 업로드**.
- scope: 업로드 + 다운로드 + 목록 + 삭제 4종.
- 삭제 = 하드삭제. 권한 = IssuePermission.UPDATE(업로드/삭제) / VIEW(다운로드/목록).

### 백엔드 API 계약 (실측, IssueAttachmentController.kt)
- POST   /api/v1/issues/{key}/attachments  (multipart, part명 `file`) → 201 { data: AttachmentResponse } + Location
- GET    /api/v1/issues/{key}/attachments → 200 { data: AttachmentResponse[] }
- GET    /api/v1/issues/{key}/attachments/{attachmentId} → 200 바이트스트림 (Content-Disposition: attachment)
- DELETE /api/v1/issues/{key}/attachments/{attachmentId} → 204
- 에러: 401(미인증) / 403(권한) / 404(이슈·첨부 없음) / 413(크기 초과)
- AttachmentResponse = { id: UUID, filename, contentType, sizeBytes: Long, uploadedBy: UUID, createdAt: Instant }
