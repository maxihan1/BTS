## 도메인 정리

- **BC**: agile-planning (모듈 `backend/modules/agile-planning/`)
- **SDD 근거**: §13.3.1 — 이슈를 "시작일~종료일" 기간 막대로 표시, Epic 부모 라인 / Story·Task 자식 라인.
- **데이터 토대 (신규 스키마 0)**: FR-PL-01 의 `issues.start_date / due_date / target_date` (DATE NULL, V025) 활용. issue-tracking BC 소유.
- **cross-BC 격리**: agile-planning 은 issue-tracking 을 직접 import 금지. 날짜 데이터는 **shared-kernel 신규 포트**로 조회.
  - 기존 `BoardIssueLookupPort.BoardIssueView` 에는 날짜 필드 없음 → 타임라인 전용 신규 포트/뷰 필요 (port 형태는 spec 에서 확정 — 신규 `TimelineLookupPort` 후보).
- **새 용어 (Maxi 승인 대기)**: **타임라인 아이템 (TimelineItem)** — 타임라인 막대 1개 = 이슈 1개. start_date~due_date 기간. Epic 부모/자식 그룹화 단위.
- **범위 결정 (Maxi 확정 2026-06-26)**: **백엔드 우선 (D1~D5)**. 타임라인 조회 API + cross-BC 포트 + 백엔드 테스트까지. 프론트 Gantt 렌더(D6/D7) + Gantt 라이브러리 ADR(fr-index §A.3 #2)은 **후속 PR**.
- **범위 제외**: FR-TL-02(의존성 라인 blocks), FR-TL-03(줌)은 별도 FR.
- **기존 결정 충돌**: 없음.
- **관련 ADR**: cross-BC 타임라인 포트 형태 결정 = ADR 후보 (spec/plan 단계 확정). §A.3 #2 Gantt 라이브러리 ADR 은 후속 PR 로 이연.

## 스펙

전체 스펙. [docs/specs/2026-06-26-fr-tl-01-gantt.md](../specs/2026-06-26-fr-tl-01-gantt.md)

- `GET /api/v1/timeline?project={key}` → 날짜(start/due 중 1개+) 있는 가시 이슈를 "타임라인 아이템" 목록으로 반환 (BROWSE 권한, truncated 500).
- cross-BC 격리 — shared-kernel 신규 `TimelineLookupPort` + issue-tracking `TimelineLookupAdapter`(보드 adapter 와 동일 보안 2단 게이트 재사용).
- Epic 부모/자식 트리 조립은 프론트(D6) 책임, 백엔드는 평면 목록 + epicKey 만 반환.
