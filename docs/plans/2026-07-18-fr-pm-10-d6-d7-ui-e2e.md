### 백엔드 API 계약 (완료, #277 — `GlobalPermissionGrantController`)

모두 `/api/v1/admin/global-permissions`, SYSTEM_ADMIN 전용, 이중 가드(PAT 포함).

| 메서드 | 경로 | 요청 | 응답 | 에러 |
|---|---|---|---|---|
| POST | `/api/v1/admin/global-permissions` | `{ permission: string, granteeType: 'USER'\|'GROUP', granteeId: uuid }` | 201 `GrantResponse` | 400 unknown_permission · 401 · 403 · 404 grantee_not_found · 409 grant_already_exists |
| GET | `/api/v1/admin/global-permissions` | — | 200 `GrantResponse[]` | 401 · 403 |
| DELETE | `/api/v1/admin/global-permissions/{grantId}` | — | 204 | 401 · 403 · 404 grant_not_found |

`GrantResponse = { id: uuid, permission: string, granteeType: 'USER'|'GROUP', granteeId: uuid, grantedBy: uuid, createdAt: instant }`

- **권한코드는 현재 `CREATE_PROJECT` 단일** (DB CHECK). grantedBy는 서버가 인증 actor에서 취함(클라 입력 아님).
- **목록은 UUID만 반환** — 표시 이름 없음. 프론트가 grantee/grantedBy UUID를 이름으로 해소해야 함.

### 프론트 통합 지점 (Explore 조사 결과, 메인 트리 경로)

1. **라우팅** — code-based `apps/web/src/router.ts` (파일 기반 아님). 새 라우트 3곳 수정: import 추가 → `createRoute`(템플릿 = `adminAuditLogsRoute`, `path:'/admin/global-permissions'`, `beforeLoad: composeGuards(requireAuth, requireSystemAdmin, requirePasswordChanged, requireMfaEnrolled)`) → `routeTree.addChildren([...])` 배열 추가. 페이지 컴포넌트는 `routes/admin.global-permissions.tsx` 에 `*RouteAdapter` export.
2. **네비** — `apps/web/src/components/Header.tsx` `ADMIN_LINKS` 배열에 `{ to:'/admin/global-permissions', label:'전역 권한' }` 한 줄. 관리 메뉴 nav `aria-label="관리 메뉴"` (E2E 계약, [[frontend-nav-aria-label-e2e-contract]]), `isAdmin = user?.isSystemAdmin === true` 게이팅.
3. **★ 최근접 선례 = field-permissions UI** (grant/revoke/list 동형):
   - 라우트 `routes/projects.$projectKey.settings.field-permissions.tsx` (단 그건 프로젝트 스코프, 우린 전역 admin 스코프)
   - 컴포넌트 `components/field-permissions/` — `FieldPermissionList`(목록) · `FieldPermissionRow`(행+삭제) · `FieldPermissionFormDialog`(부여, useGroups 드롭다운)
   - API `api/field-permissions.ts` — `fetchFieldPermissions`(GET) · `createFieldPermission`(POST) · `deleteFieldPermission`(DELETE, raw apiFetch + `X-XSRF-TOKEN`)
   - E2E `e2e/field-permissions.spec.ts` — heading getByRole, 삭제 버튼 aria-label, `X-MSW-Seed-*` 시드
4. **SYSTEM_ADMIN 게이팅** — whoami `WhoamiResponseSchema.isSystemAdmin: z.boolean()` (`api/schemas.ts`), 라우트 가드 `auth/routeGuard.ts` `requireSystemAdmin()` (=== true, deny-by-default), authStore `useAuthUser()`.
5. **grantee UUID→이름 해소** (둘 다 존재):
   - USER: `api/users.ts` `fetchUsersByIds(ids)` → `GET /api/v1/users?ids=` / 훅 `useUsersByIds`. 검색은 `useUserSearch(query)` (min 2자).
   - GROUP: `api/groups.ts` `fetchGroups()` / 훅 `useGroups()` — 목록 조회 후 id find. `GroupResponse.name`.
6. **API 관례** — `api/client.ts` `apiGet`/`apiPost`(Zod 파싱), DELETE는 raw `apiFetch(path,{method:'DELETE', headers:{'X-XSRF-TOKEN':readXsrfToken()}})`. JWT는 sessionStorage(`bts.auth`), 401→refresh+1회 retry 자동. Zod는 `api/*.ts` 콜로케이트, queryKey 팩토리, MSW는 `mocks/*-handlers.ts` → `mocks/handlers.ts` 등록.
