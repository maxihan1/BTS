## Brief

이슈 목록에서 다중 선택 + 일괄 액션 바(일괄 편집 / 일괄 상태 전이)를 구현한다.
요청을 `POST /api/v1/issues/bulk-update`(202 + bulkOperationId)로 접수한 뒤,
`GET /api/v1/bulk-operations/{id}`로 진행률/결과를 폴링해 표시한다(actor 본인 한정).

- 백엔드 API는 PR #54(접수/조회) + #56(처리)로 이미 main 머지 완료.
- 비동기 "진동벨" 아키텍처: 접수 202 → pgmq 워커 백그라운드 처리 → 진행률 폴링 조회.
- best-effort 부분성공: 이슈별 독립 처리, 실패만 reasonCode 반환.
