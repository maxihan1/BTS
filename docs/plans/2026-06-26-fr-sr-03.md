## 도메인 정리

- **BC**: search-export-import (7번째 모듈, FR-SR-02 신설). **영속성 첫 도입** — 현재 AQL 파서+컨트롤러만, DB 의존성(flyway/jOOQ/postgres/Testcontainers) 없음. SavedFilter가 이 모듈 첫 영속 엔티티.
- **영향 엔티티/테이블**:
  - `saved_filters(id, owner_id UUID, name, aql_query, project_key, created_at, updated_at, version)` (신규)
  - `saved_filter_shares(filter_id, share_type, target_id)` (신규, 공유 다대다)
  - `favorites`(FR-UX-02, notification BC) **재사용** — target_type=FILTER (즐겨찾기, 신규 컬럼 없음)
- **새 용어**: SavedFilter(저장된 필터), ShareType(PROJECT/GROUP/AUTHENTICATED — Jira식 대상 지정 공유)
- **Maxi 확정 결정 2건**:
  1. 즐겨찾기 = 기존 FR-UX-02 favorites 재사용 (지라 정합, 사용자별 북마크가 정확한 모델). saved_filters에 is_favorite 없음.
  2. 공유 = 특정 대상 지정까지 (PROJECT/GROUP/AUTHENTICATED). 단일 enum 아님.
- **SDD 10.3 deviation** (ADR 정정):
  - `isFavorite: Boolean` 인라인 → favorites 재사용 (공유 시 단일 컬럼 모델 붕괴)
  - `shareScope` 단일 enum + `shareTargetIds: List<Long>` → `saved_filter_shares` 조인 테이블
  - id/ownerId `Long` → UUID (BTS 전 모듈 관례)
- **신규 cross-BC 포트 필요** (가시성 판정):
  - `GroupMembershipPort` (identity-access 구현) — 그룹 공유 가시성. 그룹 멤버십은 현재 identity-access 내부(JdbcUserGroupRepository)에만 있음.
  - 프로젝트 멤버십 판정 — 기존 권한 인프라(IssueVisibilityPort/permission resolver) 재사용 우선 조사, 부재 시 신규 포트.
  - fail-closed (IssueVisibilityPort 선례, allow-all default 금지).
- **마이그레이션 범위**: search-export-import에 **V600~V699** 신규 할당 (DATA.md 표 전수 동기화 대상). 첫 마이그 `V600__saved_filters.sql`.
- **기존 결정 충돌**: 없음. SR-01/SR-02 엔드포인트 무변경, 검색 실행은 기존 IssueSearchPort 재사용.
- **관련 ADR**: [docs/decisions/2026-06-26-fr-sr-03-saved-filters.md](../decisions/2026-06-26-fr-sr-03-saved-filters.md) (생성됨)
- **범위/분할 권고**: 백엔드 D1~D5 / 프론트 D6~D7 분리 (FR-SR-01/02 선례). 백엔드도 부트스트랩+CRUD+PRIVATE → 공유 2분할 검토 (plan에서 확정).
