## 도메인 정리

**FR-WF-04~07 은 「워크플로우가 읽기 전용」이라는 구조적 부재를 닫는다.**
표준 4종이 YAML 에 하드코딩돼 있고 `YamlSeedService` 가 기동마다 DB 를 YAML 로 되돌린다.
워크플로우·상태·전환·검증기를 만들거나 고치는 API 가 하나도 없다. FR-WF-02 가 구현한 것은
**기존 워크플로우를 이슈 타입에 배정하는 스킴 매핑**이지 워크플로우 자체의 편집이 아니다.

- FR-WF-04 워크플로우 CRUD + 전역 상태 카탈로그
- FR-WF-05 전환 ID 식별자 — 같은 상태쌍 다중 전환 · 전역/최초 전환
- FR-WF-06 전환 규칙(조건/검증기/후처리) 편집
- FR-WF-07 초안·발행 + 상태 제거 시 이슈 이관 마법사

**용어가 갈린 경위.** 위 4건의 문서를 쓰면서 Transition 을 「전환」으로 불렀다.
그런데 저장소 정본은 「전이」였다 — `Maxi_wiki/BTS/glossary.md` 의
`| 전이 | Transition. 상태 → 상태로 가는 액션 |`, i18n 실물 문자열
`'이슈 상태 전이'`·`'허용되지 않는 전이'`. 저장소에서 「전환」이 Transition 뜻으로 쓰인 곳은
**0건**이었다(전부 뷰 전환·값 전환 같은 다른 뜻). Maxi 가 Jira 한국어 화면 표기에 맞춰
**「전환」을 정본으로** 확정했고, 이 PR 이 그 결정을 저장소 전체에 반영한다.

## 스펙

### 치환 규칙 — 낱말 단위 판정 + 3중 예외

「전이」를 기계로 치환하면 **문장이 깨진다.** 실측으로 확인한 파손 유형 4가지.

| 유형 | 예 | 처리 |
|---|---|---|
| 다른 낱말의 부분문자열 | 「버전이 갈린다」·「이전이 아니라」·「탈락 기전이 없다」 | 낱말 예외 28종 |
| 수학적 이행성(transitive) | 「전이적으로 더한다」·「전이 폐포」·「전이 의존」 | 낱말 + 구절 예외 |
| 「~하기 전(前)이다」 | 「병목은 시작 전이다」·「인증 전이라」·「측정 전이면」 | 구절 예외 31건 |
| 조사 불일치 | 「전이」는 모음 끝, 「전환」은 자음 끝 | 조사 보정 10종 |

조사 보정이 없으면 「전환가·전환를·전환는·전환로·전환와·전환다·전환면·전환여야」라는
비문이 **395곳**에 생긴다.

### 손대지 않는 곳 — 3종

| 대상 | 이유 |
|---|---|
| `**/db/migration/**` SQL 21곳 | **Flyway 가 적용된 마이그레이션의 체크섬을 검증한다.** 파일을 고치면 이미 그 버전을 기록한 DB 에서 기동이 막힌다(`validateOnMigrate` 기본 true, `FlywayAssemblyConfig` 에 끄는 설정 없음) |
| `docs/progress.html` 115곳 | 자동 생성물. 원본(`TODOS.md`)을 고치고 생성기를 다시 돌린다 |
| `classify-task.ts` 의 `'전이'` 키워드 · `classify-task.test.ts` | 구 표기를 **일부러** 남긴다 — git 이력·닫힌 브랜치·저장소 밖 메모리·동결된 마이그레이션이 여전히 그 표기를 쓴다 |

### 판별식 — 「전환」은 도메인 구절로만 잡는다

`BC_KEYWORDS` 에 「전환」을 **단독으로** 넣으면 `self-hosted 러너로 전환`·`MSW 를 v2 로 전환`
같은 일반 동사 제목이 project-workflow 로 끌려온다(실측). 그래서
`상태 전환`·`전환 규칙`·`전환 id`·`전역 전환` 네 구절로만 잡는다.

### T6~T7 이 왜 이 PR 에 들어왔나

`todos-reorder-integrity.test.ts` 의 F2b 축은 개명(제목만 바뀜)은 접지만
**편집(본문만 바뀜)은 소실로 셌다.** 그 결과 부채 항목 본문의 낱말 하나를 고치는 것만으로
「부채 항목이 사라졌다」 red 가 났다 — **어떤 PR 도 부채 항목 본문을 고칠 수 없는 상태**였다.
개명을 접는 논리의 거울상이 빠진 것이라 같은 PR 에서 대칭으로 채운다.
접는 조건에 **본문 줄 수가 줄지 않았을 것**을 넣어, 원래 목적(본문 소실 탐지)은 유지한다.
