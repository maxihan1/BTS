## Brief

FR-IM-01(CSV/JSON Import, Jira 마이그레이션)의 프론트엔드 UI 단계.
백엔드 PR1~PR4(#218/#221/#224/#226)로 코어·컴포넌트/버전·댓글/Worklog·첨부/이력 Import가 모두 완료됨.
이제 D6(파일 업로드 + 진행률) + D7(E2E)를 구현한다.

- 백엔드 API. `POST /api/v1/imports`(멀티파트: CSV/JSON 파일 + optional attachmentsZip), `GET /api/v1/imports/{id}`(진행률/상태 폴링), 결과 로그 CSV 다운로드.
- 구조 참고. FR-EX-02(비동기 Export) 프론트(#206)의 역방향 미러 — ExportDialog 상태머신 + 폴링 hook 패턴 재사용.
- 범위 밖. FR-IM-02(매핑 마법사)는 별도 FR.

## 도메인 정리

- **BC**. search-export-import(논리). 프론트는 REST 소비 뷰 레이어(apps/web). 새 도메인 엔티티·용어 0 — ImportJob·dry-run·errorLog·status(PENDING/RUNNING/COMPLETED/FAILED)는 백엔드 PR1~4에서 확정.
- **API 계약**(정밀 확인 완료 — grep 근거).
  - `POST /api/v1/imports` (multipart, 202) — `file`(필수)·`attachmentsZip`(선택)·`projectKey`(필수)·`format`("CSV"/"JSON" 대소문자 무관)·`dryRun`(기본 false) → `ImportJobResponse`
  - `GET /api/v1/imports/{jobId}` (200) — 폴링 → `ImportJobResponse`
  - `GET /api/v1/imports/{jobId}/errors` (200) — 실패행 에러 로그 CSV 스트림(Content-Disposition attachment)
  - `ImportJobResponse` = { jobId:UUID, status:String, progress:Int(0~100), totalRows:Long?, succeededRows:Long, failedRows:Long, errorCode:String?, errorLogReady:Boolean, dryRun:Boolean }. `@JsonInclude(NON_NULL)` → nullable 필드는 Zod `.nullish()`.
  - 에러코드. HTTP: IMPORT_ACCESS_DENIED(403)·IMPORT_FILE_TOO_LARGE(413)·IMPORT_UNSUPPORTED_FORMAT(400)·IMPORT_VALIDATION_FAILED(400)·IMPORT_INTERNAL_ERROR(500). 잡 컬럼값: IMPORT_ROW_LIMIT_EXCEEDED·IMPORT_PARSE_FAILED.
- **미러 대상**(FR-EX-02 역방향). `apps/web/src/hooks/use-export-job-polling.ts`(react-query v5 refetchInterval=(query)=>, 종단 COMPLETED/FAILED 중단, error 중단) + `apps/web/src/components/search/ExportDialog.tsx`(상태머신).
- **진입점**. projectKey 필수 → 프로젝트 스코프. `/projects/$projectKey/settings/import` 전용 페이지 유력(components/versions/custom-fields 형제). **spec 단계 Maxi 확인**.
- **기존 결정 충돌**. 없음. 신규 ADR 불요(에픽 ADR `docs/decisions/2026-07-02-fr-im-01-csv-json-import.md` 재사용, view-layer 소비).
- **회귀 주의**. router.ts 라우트 카운트 하드코딩 금지(동시세션 충돌 대비, FR-RP-03 교훈). Zod↔백엔드 DTO drift(frontend-zod-backend-dto-contract-gap).

## 스펙

전체 스펙. [docs/specs/2026-07-03-fr-im-01-d6-d7-import.md](../specs/2026-07-03-fr-im-01-d6-d7-import.md)

**Maxi 결정**. ①진입점=프로젝트 설정 전용 페이지 `/projects/$projectKey/settings/import` ②dry-run=2-step(검증 먼저→실제) ③첨부 zip=v1 포함.

핵심 3줄.
- 설정 페이지 폼(format·파일·JSON일 때 첨부 zip) → [검증만 실행]/[Import 시작] → 진행률 폴링(1500ms) → done.
- dry-run done에서 "이 파일로 실제 Import"(같은 file 재사용). errorLogReady면 에러 로그 CSV 다운로드.
- FR-EX-02 Export 프론트 역방향 미러(상태머신 + 폴링 hook + Zod .nullish). 백엔드 변경 0.
