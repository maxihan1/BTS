## Brief

FR-API-04 — 사용자가 API 호출용 개인 액세스 토큰(PAT)을 발급/회전/취소하는 셀프서비스 기능. product §5.4(논리 소속 search-export-import, 선행 identity-access §2.9). Maxi 확정: type=auth, security-engineer 주도.

**선행 자산(FR-AU-09 #37, 2026-05-29)**: PAT 백엔드 상당 부분 존재 — V006 personal_access_tokens(token_hash SHA-256·scopes JSON·expires_at nullable 무기한), PersonalAccessTokenService, SecurityConfig PAT 인증 미들웨어, PAT scopes 감사(FR-AU-10). → FR-API-04 실제 신규 범위는 domain에서 실물 grep으로 gap 확정(FR-API-03 PR4 계약 실물검증 선례). 추정: D6 프론트 UI(발급/회전/취소, DEVELOPMENT §1.17 토큰 1회만·localStorage 금지) + D7 E2E + 누락 백엔드(회전 rotation·scope 선택·TTL default).

- **기존 자산(FR-AU-09 #37, 재사용)**: V006 스키마 · `PatAuthenticationFilter`(Bearer `pat_`→verify→ROLE_PAT) · `verify`/`hasScope`(와일드카드 `*`) · CSRF 스킵 · `isExpired`. **검증 인프라 완비, 발급/관리/UI만 신규.**
- **새 용어**: PAT scope 카탈로그 (supportedScopes — 발급 시 선택 가능한 권한 범위 목록. glossary 미등록 → 추가 후보)
- **기존 결정 deviation**: [session-pat-schema](../decisions/2026-05-20-session-pat-schema.md) EC-27(무기한 허용, "후속 PR에서 1년 default 검토") → 본 PR에서 **무기한 금지·사용자 선택 최대 1년**으로 확정. DB 스키마 무변경(`expires_at` nullable 유지, 애플리케이션 레벨 검증, 마이그레이션 0).
- **Maxi 결정 3건 (2026-07-02)**:
  1. **scope**: 발급/관리 + 저장·표시만 (전면 강제=전 API scope 매핑은 후속, `hasScope()` 인프라 재사용)
  2. **회전**: 취소+재발급으로 충분 (별도 rotate API 없음, GitHub PAT 방식)
  3. **TTL**: 사용자 선택 최대 1년 (무기한 금지, `now+365일` 상한)
- **관련 ADR**: [session-pat-schema](../decisions/2026-05-20-session-pat-schema.md)(V006·scope JSONB) + [fr-api-04-pat-management](../decisions/2026-07-02-fr-api-04-pat-management.md)(신설 — 본 PR 정책)
- **BC 격리**: search-export-import 논리 소속이나 물리 구현은 identity-access 단일 BC(PAT 인프라 소재). cross-BC 호출 0.

## 스펙

전체 스펙. [docs/specs/2026-07-02-fr-api-04-pat.md](../specs/2026-07-02-fr-api-04-pat.md)

핵심 시나리오 3줄 요약.
- 발급 `POST /api/v1/users/me/pats` {name, scopes(5종 카탈로그), expiresInDays 1..365} → `pat_`+48자 CSPRNG 원본 **1회 노출**(SHA-256 저장), 활성 **20개 상한**.
- 목록 `GET`(미취소 전부·만료 배지) / 취소 `DELETE {id}`(**소유권 바인딩 IDOR 방지**·멱등 204). PAT 자격증명 호출은 **403**(JWT 전용, TrustedDeviceController 선례).
- 프론트 `/settings/pats` — 발급 폼 + 토큰 1회 모달(localStorage 금지) + **scope 미강제 경고**(계정 전체 권한 disclosure).

Maxi 결정 4건(2026-07-02): 개수상한 20 · `PAT_ISSUED`/`PAT_REVOKED` 감사(enum 22→24) · scope 미강제 disclosure · 카탈로그 5종(`read:issues`·`write:issues`·`read:projects`·`write:projects`·`*`).
