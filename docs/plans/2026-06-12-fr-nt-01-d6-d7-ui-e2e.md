### 잠긴 API 계약 (백엔드 #118 — UI/E2E가 그대로 박제. Zod↔DTO drift 방지)

Base: `/api/v1/notification-policies`. 성공 응답은 `{ "data": T }` 래퍼(DataResponse).

| 메서드 | 경로 | 요청 | 성공 | 권한 |
|---|---|---|---|---|
| GET | `/catalog` | — | 200 `{data: PolicyCatalogResponse}` | 인증만(비-admin도 OK) |
| GET | `?projectKey=` | (projectKey 선택) | 200 `{data: NotificationPolicyResponse[]}` | SYSTEM_ADMIN |
| POST | `/` | CreatePolicyRequest | 201 `{data: NotificationPolicyResponse}` | SYSTEM_ADMIN |
| PATCH | `/{id}` | TogglePolicyRequest | 204 No Content | SYSTEM_ADMIN |
| DELETE | `/{id}` | — | 204 No Content | SYSTEM_ADMIN |

**NotificationPolicyResponse**: `id`(UUID), `projectKey`(string?, null이면 키 생략=NON_NULL), `eventType`(wireValue 문자열 e.g. `"issue.created"`), `recipientRole`(enum NAME e.g. `"REPORTER"`), `channel`(enum NAME e.g. `"EMAIL"`), `enabled`(bool), `createdAt`/`updatedAt`(Instant ISO-8601).

**CreatePolicyRequest**: `projectKey`(string?), `eventType`(string, NotBlank), `recipientRole`(string, NotBlank), `channel`(string, NotBlank), `enabled`(bool, 기본 true).

**TogglePolicyRequest**: `enabled`(bool). ⚠️ PATCH는 **enabled만** 토글 — 조합(event/role/channel) 수정은 없음. 변경하려면 삭제 후 재생성.

**PolicyCatalogResponse**: `eventTypes`(`{value, publishable}[]`), `recipientRoles`(string[]), `channels`(string[]). 서버 enum이 진실 출처.

**enum 값(정확)**:
- eventType wireValue 9종: `issue.created`(publishable) · `issue.assigned` · `issue.transitioned`(publishable) · `issue.commented` · `issue.due_soon` · `issue.overdue` · `sprint.started` · `sprint.ended` · `automation.failed`
- recipientRole NAME 9종: `REPORTER` · `ASSIGNEE` · `PREVIOUS_ASSIGNEE` · `WATCHER` · `COMPONENT_LEAD` · `MENTIONED` · `PROJECT_MEMBER` · `RULE_OWNER` · `PROJECT_ADMIN`
- channel NAME 5종: `EMAIL` · `IN_APP` · `SLACK` · `TEAMS` · `WEBHOOK`

**에러(RFC7807 ProblemDetail, `errorCode` 프로퍼티 포함)**:
- 400 `NOTIF_VALIDATION_FAILED`(@Valid 실패) · 400 `NOTIF_INVALID_ENUM`(알 수 없는 enum)
- 401(미인증, ResponseStatusException) · 403 `NOTIF_FORBIDDEN`(비-admin)
- 404 `NOTIF_POLICY_NOT_FOUND` · 409 `NOTIF_POLICY_DUPLICATE`(동일 조합 중복) · 500 `NOTIF_INTERNAL_ERROR`

### 평가 의미(UI 표현에 영향)
프로젝트 정책은 해당 event_type에 대해 전역을 **replace**(병합 아님)한다. UI는 "전역 vs 프로젝트" 범위를 명확히 구분 표시해야 함(#118 평가엔진).
