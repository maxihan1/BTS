## 도메인 정리

- **BC**: issue-tracking (물리 구현). 논리 FR 소속은 search-export-import 유지 (논리 ≠ 물리, ADR D1/D2).
- **영향 영역**: 프론트엔드 이슈 목록 화면 (apps/web). 백엔드 0 변경(이미 #180 완료).
- **새 용어**: 없음. 필터 4종(status/assignee/label/component)은 기존 개념. status=워크플로우 상태,
  assignee=담당자(unassigned 센티널 포함), label=라벨 이름, component=컴포넌트.
- **API 계약 (소비 대상, #180)**:
  - `GET /api/v1/issues?projectKey=&status=&assignee=&label=&component=&page=&size=`
  - 같은 파라미터 다중 값 = OR, 다른 파라미터 간 = AND (괄호/중첩 미지원 — 그건 FR-SR-02 AQL).
  - assignee: UUID 또는 `"unassigned"`(대소문자 구분 센티널). label: 이름 문자열. component: UUID.
  - 잘못된 UUID → 400 `ISSUE_FILTER_INVALID_UUID`.
  - 응답: `Page<IssueResponse>` (기존 목록 응답과 동일 스키마).
- **기존 결정 충돌**: 없음.
- **관련 ADR**: [docs/decisions/2026-06-23-fr-sr-01-issue-filter-bc.md](../decisions/2026-06-23-fr-sr-01-issue-filter-bc.md)
  (백엔드 PR #180에서 생성, D6/D7은 신규 ADR 불필요).
- **참고**: 보드 필터(FR-BD-02)가 동일 4필드 필터 UI를 이미 보유 가능 → 재사용/패턴 정렬 확인 필요(spec에서).

### Task 1. api/issues.ts — `fetchIssues` 필터 확장 + `IssueFilterParams` + query 조립

**메타**.
- agent: `frontend-engineer`
- files: [`apps/web/src/api/issues.ts`, `apps/web/src/api/issues.test.ts`]
- depends-on: []

**RED**: `issues.test.ts` — `fetchIssues({ projectKey, page, size, filter })`가 올바른 query string 생성(fetch mock URL 단언).
- `{ statusKeys:['open','in_progress'] }` → `?...&status=open&status=in_progress`
- `{ assigneeIds:['a1'], includeUnassigned:true }` → `?...&assignee=a1&assignee=unassigned`
- `{ labels:['bug'] }` → `?...&label=bug`, `{ componentIds:['c1'] }` → `?...&component=c1`
- 빈 필터 / filter 미전달 → 필터 param 없음(기존 `projectKey&page&size`만, 하위호환).

**GREEN**: `IssueFilterParams = { statusKeys: string[]; assigneeIds: string[]; includeUnassigned: boolean; labels: string[]; componentIds: string[] }` export + `buildIssueFilterQuery(params, filter?)` 헬퍼(URLSearchParams append, `unassigned` 센티널, 빈 배열 생략) + `FetchIssuesParams`에 `filter?: IssueFilterParams` 추가. 응답 스키마 불변.

**REFACTOR**: query 조립 KDoc, 빈-필터 단축 경로. 기존 `fetchIssues({projectKey,page,size})` 호출 호환 명시.

**검증**: `pnpm --filter web test issues.test`
