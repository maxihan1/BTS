## Brief

FR-CM-04(컴포넌트 리드 부재 시 프로젝트 리드 기본 담당자 폴백)의 D6 프론트엔드 단계.
프로젝트 설정 화면에 프로젝트 리드를 지정/해제하는 UI를 추가한다.

- 백엔드는 PR #89(squash 5c9db97b)에 머지 완료.
  - `PATCH /api/v1/projects/{idOrKey}/lead` — 2-state(지정/해제) 엔드포인트.
  - 권한: MANAGE_COMPONENTS(ComponentPermission.UPDATE, PROJECT_ADMIN 전용) 재사용.
  - 폴백 체인: 컴포넌트 리드(1순위) → 프로젝트 리드(2순위) → 미할당.
- 이번 범위: 프론트 UI만. E2E(D7)는 후속 분리(단, UI PR이 기존 E2E를 깨는지 점검 필요 — learnings).
