### 백엔드 API 계약 (프론트가 따라야 할 정본 — PR #96)

**정의 CRUD** (`/api/v1/projects/{projectIdOrKey}/custom-fields`)
| 메서드 | 경로 | 권한 | 성공 | 비고 |
|---|---|---|---|---|
| POST | `.../custom-fields` | MANAGE_CUSTOM_FIELDS | 201 | 생성 |
| GET | `.../custom-fields` | 없음(조회권) | 200 | 활성만, displayOrder asc |
| GET | `.../custom-fields/{fieldId}` | 없음 | 200 | 단건 |
| PATCH | `.../custom-fields/{fieldId}` | MANAGE_CUSTOM_FIELDS | 200 | null=무변경, fieldType·key 불변(422) |
| DELETE | `.../custom-fields/{fieldId}` | MANAGE_CUSTOM_FIELDS | 204 | 소프트 삭제, 기존 이슈 값 보존 |

**Create 요청**: key(@NotBlank,≤64) · name(@NotBlank,≤255) · description?(≤1000) · fieldType(enum) · required(기본 false) · displayOrder(기본 0) · options[]{value(@NotBlank),label(@NotBlank),displayOrder}
**Update 요청**: 위 필드 전부 nullable(null=무변경) · fieldType/key 변경 시 422(CUSTOM_FIELD_IMMUTABLE_CHANGE) · options 지정 시 전체 교체
**Response(`{data: CustomFieldResponse}`)**: id(UUID) · projectId(UUID) · key · name · description? · fieldType · required · displayOrder · options[]{value,label,displayOrder}

**FieldType 10종**: SHORT_TEXT · LONG_TEXT · NUMBER · DATE · DATETIME · SINGLE_SELECT · MULTI_SELECT · CHECKBOX · RADIO · URL
선택형(options 필수) = **SINGLE_SELECT · MULTI_SELECT · RADIO**

**값 검증(E1~E11, 서버 422)**: 미정의키 거부 · required 누락 거부 · 타입별 형식(SHORT_TEXT≤255 · LONG_TEXT≤32768 · NUMBER 유한값 · DATE `^\d{4}-\d{2}-\d{2}$` · DATETIME ISO8601 · SINGLE/RADIO=옵션 중 하나 · MULTI=List<String> 각 요소 옵션 · CHECKBOX boolean · URL `^https?://.+`)

**에러코드**: VALIDATION_FAILED(400) · CUSTOM_FIELD_NOT_FOUND(404) · CUSTOM_FIELD_PROJECT_NOT_FOUND(404) · CUSTOM_FIELD_KEY_DUPLICATE(409) · CUSTOM_FIELD_ACCESS_DENIED(403) · CUSTOM_FIELD_INVALID_DEFINITION(422) · CUSTOM_FIELD_IMMUTABLE_CHANGE(422). errorCode는 RFC7807 ProblemDetail `errorCode` 필드.

**이슈 customFields 통합**
- 생성 `POST /api/v1/issues`: `customFields: Map<String,Any?>?`(null=빈맵), 값 입력 별도 권한 없음(이슈 CREATE 권한 전제)
- 수정 `PATCH /api/v1/issues/{key}`: `customFields: Map<String,Any?>?` — null=무변경, `{}`=전체제거, 키 단위 병합(값 null=키 삭제). 병합 후 required 검증
- 응답 `IssueResponse.customFields: Map<String,Any?>`(non-null, 기본 `{}`) — 단건+목록 모두 노출
