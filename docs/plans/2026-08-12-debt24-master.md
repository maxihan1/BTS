## 이 문서가 왜 있나

PR 묶음표가 **건수만 적고 어느 항목인지는 안 적으면** 두 목록(장부 24건 ↔ 묶음 11개)이
서로를 검사하지 못한다. 이 저장소의 지배적 결함 양식(`[[two-lists-never-check-each-other]]`)이
바로 그것이고, 처방은 **차집합 판별식**이다. 그래서 아래 표는 **`TODOS.md` 줄번호를 키로** 싣는다.

**대조 방법.**

```bash
# 장부 쪽 24건
grep -n '^## ⬜' TODOS.md | cut -d: -f1
# 이 문서 쪽 24건과 양방향 차집합이 0 이어야 한다
```
