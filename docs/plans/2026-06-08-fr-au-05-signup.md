## 도메인 정리

- **BC**: identity-access (패키지 루트 `com.atlas.bts.identity`)
- **새 엔티티**: 없음 — 기존 부품 조립. 로컬 계정 = `users` 행 + `local_credentials` 행 (외부 계정의 `user_external_accounts` 불필요)
- **새 용어**: "임시 비밀번호(temporary password)", "강제 비밀번호 변경(must-change-on-first-login)" — glossary 추가 후보(Maxi 승인 대기)
- **재사용 부품**:
  - `user/UserRepository.kt` `save(username,email,displayName)` — 단 UPSERT라 가입엔 INSERT 전용 경로 필요(D2)
  - `credential/LocalCredentialService.kt` `store(userId, plain)` — Argon2id 해시 저장
  - `credential/PasswordPolicy.kt` `validate(plain)` — 12자/3종 복잡도
  - `credential/ChangePasswordService.kt` — 변경 성공 시 `must_change_password` 해제 지점
  - `permission/IdentityAccessSystemPermissionResolver.kt` + `@PreAuthorize("hasRole('SYSTEM_ADMIN')")` — FR-PM-08 결선 소비
- **핵심 설계 결정(ADR 참조)**:
  - D1 `POST /api/v1/users`(UsersController 확장), SYSTEM_ADMIN 선언적 가드
  - D2 INSERT 전용 + 중복 username → 409 USERNAME_TAKEN (UPSERT 책임 침범 회피, learning PR #8)
  - D3 임시 비번 = 서버 랜덤 생성(정책 충족), 응답 1회 반환, 평문 미저장/미로깅
  - D4 `local_credentials.must_change_password BOOLEAN`(V018), 가입 시 TRUE → whoami 노출 → 프론트 가드 → 변경 시 FALSE
  - D5 리셋 제외(notification BC 부재)
- **기존 결정 충돌**: 없음 (FR-PM-08 인프라 위 확장)
- **관련 ADR**: [docs/decisions/2026-06-08-local-account-signup.md](../decisions/2026-06-08-local-account-signup.md) (생성됨), 선행 [system-admin-role](../decisions/2026-06-04-system-admin-role.md)
- **마이그레이션**: V018 신규 (현재 최신 V017). init_codegen.sql 미러 — identity-access 모듈엔 부재 확인됨, 마이그레이션 파일만 추가

### Task 1. V018 + must_change_password 자격증명 영속 계층

**메타**.
- agent: `security-engineer` (마이그레이션은 db-engineer 검토)
- files: [`MIG/V018__local_credentials_must_change_password.sql`, `BE_MAIN/credential/StoredPasswordCredential.kt`, `BE_MAIN/credential/StoredPasswordCredentialRepository.kt`, `BE_MAIN/credential/LocalCredentialService.kt`, `BE_TEST/credential/StoredPasswordCredentialRepositoryTest.kt`, `BE_TEST/credential/LocalCredentialServiceTest.kt`]
- depends-on: []

**RED**:
