`originalEstimateSeconds` 3필드가 이미 실려 있다. **백엔드 추가 작업 0.**

**B2 가 남긴 인계 3건.**
1. 카드에는 `typeKey` 만 온다 — 아이콘·유형 이름은 기존 타입 목록 API
   (`apps/web/src/api/issue-types.ts`)에서 얻어 `IssueTypeIcon({iconName, typeName})` 에 넘긴다.
   (이슈 상세가 이미 그 방식이다.)
2. `labels` 는 값이 없어도 **빈 배열**(null 아님)이라 바로 순회해도 안전하다.
3. 프론트 Zod 확장 시 **인라인 mock 전수 grep 필요** — 스키마 강화가 산재한 mock 을 동시에
   깨는 사고가 이미 있었다 (learnings.md:600).
