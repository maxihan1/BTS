# 표준 단어 — 화면 · 서버 문구

같은 뜻을 화면마다 다른 말로 부르지 않고, 영어 개념을 고유어로 하나씩 옮긴 말(지우기 · 고르기 · 걸기)을 쓰지 않으려고 정한 말이다.
같은 제품군 Test Commander 의 `docs/WORDS.md` 를 따르고, Issue Bunker 에서 사용자가 따로 고른 줄은 날짜를 적는다 (2026-11-27 · FR-UX-06 문구 정책 §8).
Jira 패리티 계약(`docs/design/jira-parity-contract.md` §2)의 `aria-label` 4종과 `<h1>` 글자는 이 표보다 앞선다.
여기 없는 말을 새로 정해야 하면 사용자에게 묻고 줄을 더한다.

| 어디 | 막는 장치 |
|------|-----------|
| 화면 글 (`apps/web/src` 의 test · mocks 밖 코드와 `apps/web/index.html`, 주석 제외) | `apps/web/src/__tests__/words.test.ts`. 아래 표의 마지막 열을 읽어 검사한다. 줄을 더하면 검사가 저절로 본다. pre-commit(루트와 `apps/web` 의 `.lintstagedrc.json`)이 화면 · 서버 코드나 이 문서를 커밋할 때마다 돌린다 |
| 서버가 사람에게 보내는 글 (`backend/modules/*/src/main/kotlin` 의 오류 응답 · 검증 메시지 · Slack · 알림 글) | 같은 test. 로그 호출 · `error()` · `check()` 같은 내부 불변식(사람에게 500 으로만 보인다) · OpenAPI 설명(`@Operation` · `@Schema` 등, 개발자 문서) 은 뺀다 |
| 문서 (설계 · 안내) | 없음. ADR · 끝난 작업 기록 · 메모리의 옛 말은 그대로 둔다 |

코드 식별자 · API 주소 · JSON 키 · 오류 코드(`SCHEME_CHANGE_STRANDS_ISSUES`)는 바꾸지 않는다.
일상 말이라 그대로 두는 것: 로그인한 「기기」(신뢰한 기기 · 다른 기기의 세션), 「옮길 상태」, 「걸린 시간」, 「조회 상한에 걸려」.

## 1. 단어

| 뜻 | 쓰는 말 | 쓰지 않는 말 | 걸러 내는 무늬 |
|----|---------|--------------|----------------|
| 값 · 상태를 다른 것으로 (「줄바꿈」 은 그대로) | 변경 | 바꾸다 · 바뀌다 | `바꾸\|바꿔\|바꾼\|바꿀\|바꿉\|바뀌\|바뀐\|바뀝\|바뀔\|바꿨\|바뀜\|(?<!줄)바꿈` |
| 여럿 중 하나를 집기 | 선택 | 고르다 | `고르\|골라\|고른\|고릅\|고를\|고름\|골랐` |
| 없애기 (상태 · 입력 · 선택 비우기는 초기화) | 삭제 · 초기화 | 지우다 | `지우\|지워\|지운\|지울\|지웁\|지웠\|지움` |
| 내용을 손보기 · 화면 다시 불러오기 | 수정 · 새로고침 | 고치다 · 새로 고침 | `고치\|고쳐\|고칠\|고친\|고칩\|고쳤\|(?<!새로)고침` |
| 일이 다 됨 · 그만두게 함 | 완료 · 종료 | 끝나다 · 끝내다 | `끝(?:나\|난\|날\|났\|납\|남\|내\|낸\|낼\|냈\|냅)` |
| 삭제한 것을 다시 살리기 · 설정을 처음 값으로 (2026-11-27 사용자. 버전의 unrelease 는 Jira 처럼 「릴리스 취소」, 확인 창의 「되돌아가기」 는 「취소」, 표시 이름을 디렉터리 값으로 맞추는 일은 화면 버튼 이름대로 「재설정」) | 복원 · 초기화 · 릴리스 취소 · 취소 | 되돌리기 · 되돌아가기 · 복구 · 되살리기 | `되돌\|되살\|복구` |
| 목록에서 덜어 내기 | 제외 · 제거 | 빼다 | `빼[기고면서]\|뺀\|뺍\|빼 ` |
| 목록을 조건으로 줄이기 | 필터 | 거르다 | `거르\|거른\|걸러` |
| 파일을 서버로 보내기 · PR 을 만들기 | 업로드 · 등록 | 올리다 | `올리\|올려\|올린\|올립\|올릴\|올렸` |
| 개수 세기 | 집계 | 세다 · 셈 | `셉니다\|셌\|셀 수\|세어\|(?<![가-힣])셈` |
| 검증 규칙을 전환에 붙이기 (2026-11-27 사용자) | 추가 · 적용 | 걸다 | `규칙을 (?:다시 )?걸\|걸린 (?:검증 )?규칙\|다시 걸[어려]` |
| 자동화 트리거가 동작함 (2026-11-27 사용자) | 실행 | 발화 | `발화` |
| 화면의 한 구역 · 입력하는 곳 · 표의 세로줄 (「칸반」 은 그대로. 백로그 · 스프린트 목록의 aria 이름은 「백로그, 5개 이슈」) | 패널 · 입력란 · 열 | 칸 | `칸(?!반)` |
| 평소 대화에서 쓰는 말 | 이유 · 단어 · 종류 · 형태 | 까닭 · 낱말 · 갈래 · 꼴 | `까닭\|낱말\|갈래\|(?<![가-힣])꼴` |
| 이슈 트래킹 제품 | Issue Bunker | BTS | `(?<![\w.-])BTS(?![\w.-])` |
| 안내 · 오류 문장의 말끝 (Test Commander 와 같게) | ~합니다 · ~하세요 · ~할까요? | ~해요 · ~했어요 | `(?:어\|아\|여\|해\|돼\|에\|예\|네)요(?![가-힣])` |
| 두 문장을 잇기 · 이름과 값을 잇기 (2026-11-27 사용자) | 마침표로 끊은 두 문장 · 「이름: 값」 | 대시(—)로 이은 문장 | `\s—\s` |

빈 값 자리의 `—` 하나(표에서 값 없음)는 문장을 잇는 것이 아니라서 걸리지 않는다.
안내 · 오류 문장이 「~다」 · 「~할 것」 으로 끝나는 반말도 같은 test 가 막는다(이 표 밖의 따로 된 검사).
