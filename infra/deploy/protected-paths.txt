#
# 이 파일이 정본이다. 두 곳이 읽는다.
#   infra/deploy/bts-deploy.sh   rsync `--delete` 에서 제외한다 (지우면 안 된다)
#   infra/jenkins/bootstrap.sh   chown 후 root 소유로 되돌린다 (파이프라인이 읽으면 안 된다)
#
# ★목록을 어느 한쪽 스크립트에 직접 적지 마라. 두 벌이 되면 한쪽만 고쳐지고,
#   그 순간 「지워질 것」과 「읽힐 것」이 조용히 늘어난다 — 이 저장소의 지배 결함 양식이다.
#   계약. scripts/workflow/deploy-protected-paths-single-source.test.ts
#
# 형식. 한 줄에 경로 하나. `/opt/bts` 기준 상대경로. `#` 주석과 빈 줄은 무시된다.
